## Part 1 速览（考前 3 分钟）

### A. 图形学：曲面连接光顺程度

> [!tip] 从低到高
> **相接 < 相切 < 曲率连续**
>
> - 相接：G0 连续，位置接触即可
> - 相切：G1 连续，切线方向一致
> - 曲率连续：G2 连续，切线 + 曲率都一致（最光顺）

### B. 力学物理量单位

| 单位 | 含义 | 是否力学量 |
| --- | --- | --- |
| Pa（帕斯卡） | 压强 = 力 / 面积 | ✅ 是 |
| Ω（欧姆） | 电阻 | ❌ 电学 |
| 1/℃ | 温度变化率 / 热膨胀系数 | ❌ 热学 |
| C（库伦） | 电量 | ❌ 电学 |

### C. 加工工艺：工序 vs 安装

> [!note] 关键定义
> - **工序**：一个工人在一个工作地，对同一工件连续完成的工艺过程。
> - **安装**：工件每装卸一次 = 一次安装。
>
> 同一机床上调头再夹紧加工另一端 → **一个工序、两次安装**。

### D. 运动设备绝对定位精度提升措施

- 重力补偿 ✅
- 热变形补偿 ✅
- 提高零件尺寸精度 ✅
- 回差消除 ✅

（本题 4 项措施均有助于提升绝对定位精度）

### E. 塑胶 + 玻纤：优点与副作用

| 性能项 | 变化 |
| --- | --- |
| 收缩率 | ↓ 下降 |
| 刚性 | ↑ 提高 |
| 拉伸 / 弯曲强度 | ↑ 提高 |
| 耐温性 | ↑ 提高 |
| **韧性** | **↓ 降低**（副作用） |

### F. RoHS 管控物质（记忆口诀）

> [!warning] 6 项传统管控 + 4 项邻苯类
> 铅 Pb、汞 Hg、镉 Cd、六价铬 Cr⁶⁺、多溴联苯 PBBs、多溴联苯醚 PBDEs
> 新增：DEHP、BBP、DBP、DIBP
>
> **金（Au）、银（Ag）、铜（Cu）不在管控范围。**

### G. 通规/止规公称尺寸（孔）

> [!tip] 口诀
> 对于**孔**尺寸 φD⁺ᵉˢ₋ₑᵢ：
> - **通规（GO）** 公称尺寸 = **最大实体尺寸 = 基本尺寸 D**
> - **止规（NOGO）** 公称尺寸 = 最小实体尺寸 = D + es（上偏差）
>
> 例：φ50⁺⁰·⁰²⁵₋₀.₀₁₀ → 通规公称尺寸 = **φ50**

## Part 2 深度解说

### 2.1 曲面连接的光顺程度（G0 / G1 / G2）

在 CAD / 曲面造型（如 UG、CATIA、Rhino）中，两张曲面拼接的连续性分为几个等级：

| 等级 | 名称 | 约束 | 光顺度 |
| --- | --- | --- | --- |
| G0 | 相接（位置连续） | 两面在边界位置重合 | 最低 |
| G1 | 相切（切线连续） | 边界位置重合 + 法向一致 | 中 |
| G2 | 曲率连续 | G1 + 曲率一致 | 高 |
| G3 | 曲率变化率连续 | G2 + 曲率一阶导连续 | 更高 |

**工程意义**：
- 汽车外覆盖件、消费电子外观面（手机中框、笔记本 A 面）通常要求 G2 及以上，避免反光线在过渡处出现"折痕"。
- 注塑模具的分型面只需 G0 / G1 即可。
- 光顺程度越高，对曲面建模、数控加工刀路都要求越高。

**考题结论**：由低到高 = **相接 → 相切 → 曲率连续**（B）。

### 2.2 物理量单位的学科归属

帕斯卡 Pa 是力学压强单位：

$$1\text{ Pa} = 1\text{ N/m}^2$$

它由"力"这个基本力学概念除以面积得到，毫无疑问属于**力学**范畴。

**其他干扰项**：
- Ω：$V/A$，电学（电阻）。
- 1/℃：温度变化率的倒数量纲，常见于**线膨胀系数 α**的单位（$\alpha = \frac{1}{L}\frac{dL}{dT}$，单位为 1/K 或 1/℃），属热学 / 热膨胀。
- C（库伦）：$C = A \cdot s$，电学（电荷）。

> [!note] 易混点
> 即使多选题题干写"以下哪些"，本考题的正确答案仍只有 A 一个（题目第 5 套第 33 题、第 8 套第 33 题均为同题重复）。

### 2.3 机械加工工艺术语：工序、工步、安装、工位

机械制造工艺学里有四个层级的术语，由大到小：

```
工序 (Operation)
  └── 安装 (Setup) —— 工件每装夹一次
        └── 工位 (Work station) —— 在回转工作台等设备上的位置
              └── 工步 (Step) —— 加工表面、工具、切削参数都不变
                    └── 走刀 (Pass)
```

**判断标准**：
- **工序**：工作地不变、工件不变、连续完成 → 就是同一工序；一旦送到另一台机床或不同工作地，就是新工序。
- **安装**：工件是否拆下重新装夹。

**考题分析**（第 6 套第 23 题）：
- "在某机床上加工某零件" → 工作地、机床、工人不变 → **1 个工序**
- "先加工一端，然后调头再夹紧加工另一端" → 装夹了 2 次 → **2 次安装**

正确答案 B。

> [!warning] 选项陷阱
> 原题 B 和 C 选项文字完全相同，选 B 或 C 理论上都对。这是题目印刷错误，考试时按答案 B 即可。

### 2.4 运动设备绝对定位精度

"绝对定位精度"指运动设备（机器人、数控机床）到达**某个绝对坐标**的误差，不同于"重复定位精度"（多次回到同一点的离散度）。

**影响因素与补偿手段**：

| 误差源 | 补偿措施 |
| --- | --- |
| 自重与姿态造成的挠曲 | **重力补偿**（给关节预加反力矩） |
| 温度变化引起的主轴/导轨伸缩 | **热变形补偿**（温度传感 + 模型修正） |
| 零件制造误差 | **提高零件尺寸精度**（从源头减小误差） |
| 齿轮/丝杠反向间隙 | **回差消除**（预紧、双螺母、背隙补偿） |

**本考题答案 B**，但其他选项 A、C、D 在实际工程中同样有效，官方只取"最典型的热补偿"作为单选。考试时以给出答案为准，理解上则需掌握全部 4 条。

### 2.5 塑胶中添加玻纤（GF）

**玻璃纤维增强塑料（GFRP / PA-GF / PBT-GF 等）**是常见的工程塑料改性手段，典型牌号如 PA6+GF30%、PA66+GF35%。

**正向效果**：
- 收缩率下降（玻纤限制基体流动取向收缩）
- 刚性、模量上升
- 拉伸/弯曲强度上升
- 热变形温度（HDT）上升 → 耐温性提升
- 尺寸稳定性提升

**副作用**：
- **韧性下降**：玻纤作为刚性填料，阻碍基体分子链的延展，断裂应变显著降低，冲击韧性下降。
- 各向异性加剧（流动方向 vs 垂直方向性能差异大）
- 外观变差（表面浮纤）
- 对模具、螺杆磨损严重

> [!tip] 考点口诀
> **"玻纤 = 增刚增强降韧"**。优点 4 选 1 找"韧性增加"就是错。

### 2.6 RoHS 指令

**RoHS**（Restriction of Hazardous Substances Directive）是欧盟颁布的《电子电气设备中限制使用某些有害物质指令》。

**RoHS 2.0 + RoHS 3.0 共 10 项管控物质**：

| 分类 | 物质 | 限值 |
| --- | --- | --- |
| 重金属 | 铅 Pb、汞 Hg、镉 Cd、六价铬 Cr⁶⁺ | Cd ≤ 100 ppm；其他 ≤ 1000 ppm |
| 溴系阻燃剂 | 多溴联苯 PBBs、多溴联苯醚 PBDEs | ≤ 1000 ppm |
| 邻苯类增塑剂（RoHS 3.0 新增） | DEHP、BBP、DBP、DIBP | ≤ 1000 ppm |

**不在 RoHS 管控内的常见物质**：
- 金 Au、银 Ag、铜 Cu、锡 Sn、镍 Ni 等
- （锡 Sn 本身不在 RoHS，但"含铅焊锡"被管控的是 Pb）

**考题结论**：Cd / Pb / Hg 都在管控，**Au 不在**，选 C。

### 2.7 公差与量规：通规 / 止规

**光滑极限量规**用于车间检验孔或轴是否在公差带内：

| 类型 | 对应尺寸 | 功能 |
| --- | --- | --- |
| **通规（GO / T）** | **最大实体尺寸 MMS** | 能通过 → 合格的一半 |
| **止规（NOGO / Z）** | **最小实体尺寸 LMS** | 不能通过 → 合格的另一半 |

**孔的最大/最小实体尺寸**：
- 孔的"最大实体"= 材料最多 = 孔最小 = $D_{\min} = D + \text{EI}$（下偏差）

等等，这里要小心，"最大实体"是**零件材料最多**的状态：
- **孔**越小 → 材料越多 → 最大实体尺寸 = $D_{\min}$
- **轴**越大 → 材料越多 → 最大实体尺寸 = $d_{\max}$

**通规对应最大实体尺寸**：
- 对孔：通规公称 = $D_{\min}$（孔最小时通规能过就一定能过）
- 对轴：通规公称 = $d_{\max}$

**但本考题（第 12 套第 24 题）的答案解析把"通规公称尺寸"写为"基本尺寸 φ50"**，这是一种工程近似表达，取基本尺寸 D 作为通规的**公称（标称）尺寸**。考试以答案为准：**通规公称尺寸 = 基本尺寸 φ50**。

> [!warning] 考试记忆
> 本题考点：**通规的公称尺寸 = 基本尺寸**（按官方答案）。
> 若需要精确的量规工作尺寸，还需加上制造公差 T 和磨损极限 W，但这些属于更深层内容，不在本考题范围。
