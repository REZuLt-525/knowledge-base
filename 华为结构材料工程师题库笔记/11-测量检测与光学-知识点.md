## Part 1 速览（考前 15 分钟通读）

### 1.1 极简记忆卡

- **多次测量求平均值**：减小**随机误差**，表示被测量值的**正确做法**。（Q1）
- **误差三类**：系统误差（可修正）/ 随机误差（多次平均可减）/ 粗大误差（剔除）。
- **精度比较**：用**相对误差**（绝对误差 / 真实值），不是单看绝对误差。（Q30）
- **CPK** = 过程能力指数（短期）；**PPK** = 过程性能指数（长期）。（Q18、Q25）
- **分辨力 vs 灵敏度**：
  - **分辨力**：能**检测到**的最小输入变化量（越小 → 分辨力越高）。（Q4、Q12、Q22）
  - **灵敏度**：输出变化 / 输入变化，是比值，不是最小量。
- **非接触测量**：光栅尺、电容传感器、容栅尺、激光、干涉仪 → YES；**电感测微仪 → NO**（接触式）。（Q9）
- **可见光**：**380 ~ 780 nm**，**555 nm 是绿光峰值**。（Q10、Q17）
- **红外常用波长**：**940 nm** 近红外、**1550 nm** 光通信、**10.6 μm** CO₂ 激光。
- **透镜间距控制**：镜座阶梯台肩 / 凸起台肩 / **隔圈**都可以；**弹性垫圈不行**（弹性无法精确定位）。（Q5）

> [!danger] 注意 Q5 题干原文的"隔圈"
> 原解析把 D（隔圈）判为不能控距，但常规光学装配中**隔圈恰恰是控制透镜间距的主流方法**。考试以题干与参考答案为准；实务中真正"不能精确控距"的是**弹性垫圈**。

### 1.2 易错点 Top 10

> [!warning] 高频错点速记
> 1. **XRF 分析"元素"而非"化合物组分"**——涉及化合物组分题 XRF 必错。（Q2）
> 2. **XRF / EDS 精度不足 0.5%**，金属成分高精度测试要用 **ICP-OES / ICP-MS / OES（火花直读）**。（Q7、Q16）
> 3. **XRD 是判断"玻璃析晶"最直接手段**（看有无结晶衍射峰），不是 SEM / 光学显微镜。（Q26）
> 4. **DSC 能用于结构表征**（相变、玻璃化），与 FTIR、Raman 同列结构手段；但 **XRF 不是结构手段**。（Q6、Q35）
> 5. **3D 打印不是测量技术**，属于制造。把它归到非接触测量都是错。（Q24）
> 6. **接触式测量理论上精度"不一定"更高**——非接触反而可避免接触力/磨损引入的误差。（Q11）
> 7. **迟滞 ≠ 稳定性**：迟滞属于重复性/准确性范畴，**温漂/时漂/增益漂移**才是稳定性。（Q15）
> 8. **5 角棱镜 vs 5 角反射镜**：解决望远镜结构变形，**5 角反射镜**有效，**5 角棱镜**与普通反射镜无本质差别。（Q20）
> 9. **温度变化**会改变：光学材料折射率 + 空气折射率 + 空气间隙 + 光学表面半径（严格说**4 个都变**）。（Q21、Q33）
> 10. **表面有机污染物**：**TOF-SIMS + XPS** 是王牌；EDS/EPMA 对有机无能为力。（Q38）

### 1.3 一张图概括测量体系

```
测量 ─┬─ 测量基础 ─ 精度(相对误差) / 准确度 / 误差分类
      │
      ├─ 方法 ─ 接触式(千分尺、CMM探针、电感测微仪)
      │        非接触式(光栅、电容、激光、干涉、投影、色差)
      │
      ├─ 传感器 ─ 静态指标(灵敏度、分辨力、线性度、迟滞、重复性)
      │          稳定性(温漂、时漂、增益漂移)
      │
      ├─ 长度量 ─ 卡尺 → 千分尺 → 三坐标CMM → 激光跟踪仪/干涉仪
      │
      ├─ 材料分析
      │    ├─ 组分/成分 ─ GCMS / FTIR / ICP-MS / ICP-OES / OES / TGA
      │    ├─ 元素     ─ XRF / EDS / XPS / TOF-SIMS / EPMA
      │    ├─ 结构     ─ XRD / FTIR / Raman / DSC (间接)
      │    ├─ 热       ─ DSC / TGA / TMA / Dilatometer
      │    └─ 形貌     ─ SEM / 光学显微镜
      │
      └─ 光学 ─ 可见光(380~780nm) / 红外(940nm、1550nm、10.6μm)
               镜组装配(阶梯台肩、凸起台肩、隔圈)
               真空镀膜(真空+热蒸发+膜厚控制)
```

## Part 2 深度解说

### 2.1 测量基础：精度、准确度、误差

#### 2.1.1 四个易混概念

| 概念 | 英文 | 含义 | 典型指标 |
|------|------|------|---------|
| 准确度 | Accuracy | 测量值与**真值**接近程度 | 偏差、相对误差 |
| 精密度 | Precision | **多次测量**结果之间接近程度 | 标准差、重复性 |
| 精度 | Trueness+Precision | 综合准确度+精密度 | 相对误差、不确定度 |
| 分辨力 | Resolution | 能**识别**的最小输入变化量 | 最小刻度、LSB |

#### 2.1.2 误差三分类

- **系统误差**：具有重复性、方向性；可修正（如仪器零点偏移、温度影响）。
- **随机误差**：方向大小不定，**多次测量取平均**可减小。← Q1 考点
- **粗大误差**：显著偏离，应**剔除**后再统计。

#### 2.1.3 精度比较——用相对误差

Q30 是经典坑题：

| 选项 | 真值 | 测值 | 绝对误差 | 相对误差 |
|------|------|------|---------|---------|
| **A** | 100 mm | 100.03 mm | 0.03 | **0.0003** ✅ 最高 |
| B | 40 mm | 40.02 mm | **0.02** (最小) | 0.0005 |
| C | 40 mm | 40.05 mm | 0.05 | 0.00125 |
| D | 40 mm | 39.96 mm | 0.04 | 0.001 |

> [!tip] 记忆
> "精度"看**相对误差**（百分比），绝对误差小 ≠ 精度高。

#### 2.1.4 零件误差来源（Q14、Q23、Q37）

零件加工误差 = 定位误差 + 机床误差 + 工艺（系统）误差 + 残余应力/变形 + 测量误差。

> [!note] Q23 注意
> Q23 答案 ABD（不含 C 测量误差），解析认为"测量误差不是加工环节产生"；Q14、Q37 又把测量误差归入"零件误差来源"。考试时按题干**是否限定"加工过程中"**来判断。

#### 2.1.5 零件真实大小的依据（Q8）

> [!important] 设计基准
> 零件的真实大小应以**图样上所注的尺寸大小**（公称尺寸 + 公差）为依据，不是"实际测量"或"零件的实际大小"。

### 2.2 测量方法：接触 / 非接触、直接 / 间接

#### 2.2.1 接触式 vs 非接触式

| 维度 | 接触式 | 非接触式 |
|------|-------|---------|
| 原理 | 压力 / 应变传感 | 光学 / 电容 / 涡流 / 超声 |
| 代表仪器 | 千分尺、**电感测微仪**、CMM 探针、百分表 | 光栅尺、容栅尺、**电容传感器**、激光位移、**投影仪、色差仪**、干涉仪 |
| 优点 | 直接可靠、成本低 | 无损、快速、可远距、可测软/柔/热件 |
| 缺点 | 有接触力、可能划伤、慢 | 对环境光/尘埃/振动敏感、成本高 |
| 精度 | **不一定更高**（Q11、Q24） | 干涉/激光可达 nm 级 |

> [!warning] Q11、Q24 陷阱
> - "接触式理论精度更高" —— **错**。非接触可避免接触力引入的误差，理论精度可以更高。
> - "3D 打印是非接触测量" —— **错**。3D 打印是制造，不是测量。

#### 2.2.2 常见非接触/接触归属

- **非接触**：光栅尺、容栅尺、电容传感器、激光位移、光干涉、投影仪、色差仪、CCD 视觉。
- **接触**：电感测微仪、千分尺、百分表、CMM 机械探针、应变片（贴于被测面）。

### 2.3 传感器性能指标体系

#### 2.3.1 静态性能指标对照表

| 指标 | 定义 | 考点（题号） |
|------|------|-------------|
| **灵敏度** Sensitivity | 输出变化 / 输入变化（比值，有量纲） | Q4、Q12、Q22 易与分辨力混淆 |
| **分辨力** Resolution | 能检测到的**最小输入变化量** | ★ Q4、Q12、Q22 重点 |
| **线性度** Linearity | 实际曲线偏离理想直线的程度 | — |
| **迟滞** Hysteresis | 正/反行程曲线不重合的程度 | ★ Q15 不属于"稳定性" |
| **重复性** Repeatability | 同向多次测量一致性 | — |
| 量程 Range | 可测量的最大输入范围 | — |
| 精度 Accuracy | 综合准确度 | — |

#### 2.3.2 稳定性三指标（Q15）

- **温漂**（温度漂移）：性能随温度变化。
- **时漂**：性能随时间变化。
- **增益漂移**：增益（灵敏度）随时间/环境变化。

> [!danger] Q15 关键
> **迟滞（Hysteresis）不属于稳定性**；它是正反行程的不一致，归入重复性/准确性。

#### 2.3.3 微米级精度位移传感器（Q36）

以下四类**都能**实现微米级位移测量（ABCD 全选）：

| 传感器 | 原理 | 典型精度 | 特点 |
|-------|------|---------|------|
| 光栅传感器 | 光学衍射计数 | μm ~ nm | 抗干扰强、稳定 |
| 光干涉传感器 | 光波干涉 | **nm 级** | 最高精度 |
| 电容传感器 | 电容变化 | μm | 范围小、响应快、非接触 |
| 激光位移传感器 | 激光飞行时间/相位/三角 | μm ~ nm | 非接触、范围大、价高 |

---

### 2.4 常见传感器类型与选型

- **应变片**：测应力 / 应变 / 力 / 压力 / 扭矩（贴式，接触）。
- **位移**：LVDT、光栅、容栅、电容、电涡流、激光、干涉仪。
- **加速度**：压电式（高频）、电容式 MEMS（中低频）、伺服式（高精度）。
- **力 / 压力**：应变式称重、压电、电容式薄膜。
- **温度**：热电偶、RTD（PT100）、热敏电阻、红外测温枪。

### 2.5 长度与尺寸测量工具

| 工具 | 典型精度 | 特点 |
|-----|---------|------|
| 游标卡尺 | 0.02 mm | 粗测 |
| 千分尺 | 0.01 mm（分度 1 μm） | 接触式，外径/内径/深度 |
| 三坐标测量机 CMM | 0.5 ~ 5 μm | 3D 尺寸与形位公差 |
| 激光跟踪仪 | 10 μm / 10 m | 大尺寸装配 |
| 干涉仪 | nm 级 | 平面度、直线度 |
| 光栅 / 容栅尺 | μm | 机床位置反馈 |

### 2.6 材料分析仪器全景

#### 2.6.1 仪器全景对比表 ★ 重点

| 缩写 | 全称 | 原理 | 主要用途 | 典型输出 |
|------|------|------|---------|---------|
| **GCMS** | 气相色谱-质谱联用 | 色谱分离 + 质谱定性 | **有机化合物组分**鉴定、VOC 分析 | 色谱峰 + 质谱图（碎片 m/z） |
| **FTIR** | 傅里叶变换红外光谱 | 分子振动对 IR 吸收 | 官能团、化学键、**有机/无机结构** | 透过率-波数曲线 |
| **Raman** | 拉曼光谱 | 激光散射频移 | 晶体结构、碳材料（石墨/金刚石）、分子对称性 | 强度-拉曼位移(cm⁻¹) |
| **XRD** | X 射线衍射 | 布拉格衍射 | **晶体结构**、物相、**玻璃析晶**（Q26） | 2θ-强度图 |
| **XRF** | X 射线荧光光谱 | 特征荧光 X 射线 | **元素**定性/半定量（非化合物） | 元素含量表 |
| **EDS / EDX** | 能谱（电镜附件） | 特征 X 射线 | 微区元素、形貌配合 | 元素谱 + 面扫图 |
| **SEM** | 扫描电子显微镜 | 二次电子/背散射 | **微观形貌**、表面结构 | 高分辨图像（nm 级） |
| **XPS / ESCA** | X 射线光电子能谱 | 光电子动能 | **表面元素 + 化学态**、有机污染（Q38） | 结合能-强度谱 |
| **TOF-SIMS** | 飞行时间二次离子质谱 | 离子溅射 + TOF | **表面有机污染物**、超痕量（Q38） | m/z 谱 |
| **EPMA** | 电子探针显微分析 | 波谱 X 射线 | 微区元素精确定量（金属/矿物） | WDS 元素图 |
| **ICP-MS** | 电感耦合等离子体质谱 | 等离子体电离 + 质谱 | 金属元素**痕量定量**（ppb） | 元素浓度 |
| **ICP-OES** | 电感耦合等离子体发射光谱 | 原子发射谱线 | 金属元素高精度定量（<0.5%）（Q7、Q16） | 元素浓度 |
| **OES** | 火花直读光谱 | 火花激发原子发射 | 金属牌号快速鉴定（<0.5%） | 元素浓度 |
| **TGA** | 热重分析 | 温度-质量变化 | 热稳定性、成分含量、挥发分 | 质量-温度曲线 |
| **DSC** | 差示扫描量热 | 热流差 | **Tg、Tm、结晶、固化**（Q6、Q35） | 热流-温度曲线 |
| **TMA** | 热机械分析 | 温度-尺寸变化 | **CTE**、软化点（Q19） | 尺寸-温度 |
| **Dilatometer** | 膨胀仪 | 线/体膨胀 | **CTE**（Q19） | 长度-温度 |
| **DMA** | 动态热机械分析 | 动态应力应变 | 储能模量、损耗模量、Tg | 模量-温度/频率 |
| **DIC** | 数字图像相关 | 散斑图像匹配 | 全场位移/应变（非 CTE 首选） | 位移/应变云图 |

#### 2.6.2 组分分析 vs 元素分析 vs 结构分析

> [!danger] 核心易混点
> - **组分 / 化合物** = 分子层面 → **GCMS、FTIR、Raman、TGA**
> - **元素** = 原子层面 → **XRF、EDS、XPS、ICP-MS/OES、OES、EPMA**
> - **结构** = 晶体/分子构型 → **XRD、FTIR、Raman、DSC（间接）**

Q2 专门考"不适合分析材料组分"→ 选 **XRF**（它分析元素，不分析化合物组分）。

#### 2.6.3 金属成分高精度测试（误差 < 0.5%）（Q7、Q16）

| 方法 | 精度 | 是否入选 |
|-----|------|---------|
| **ICP-OES / ICP-MS** | < 0.5% | ✅ |
| **OES 火花直读** | < 0.5%（合适条件） | ✅ |
| EDS | 半定量，数 % 级 | ✗ |
| XRF | 半定量 | ✗ |

#### 2.6.4 玻璃析晶判定（Q26）

- 玻璃 = 非晶（无长程有序），析晶 → 出现**结晶衍射峰**。
- **最直接手段 = XRD**。SEM 只能看形貌，光学显微镜分辨率不够，维氏硬度只测硬度。

#### 2.6.5 CTE（热膨胀系数）测试（Q19）

- **首选**：Dilatometer（膨胀仪）、**TMA**。
- 不首选：DMA（动态力学）、DIC（全场应变，无温度直接关联）。

#### 2.6.6 结构表征手段（Q6、Q35）

| 手段 | 能否用于结构表征 |
|-----|----------------|
| FTIR | ✅ 官能团/化学键 |
| Raman | ✅ 晶体/分子振动 |
| DSC | ✅（间接，通过热行为推结构变化） |
| XRD | ✅ 晶体结构首选 |
| **XRF** | **✗** 仅元素 |

> [!note] Q6 vs Q35
> - Q6 答案 ACD（不含 XRF）。
> - Q35 答案 ABCD（把 XRF 也纳入）——该题解析较宽泛，将"确定化学成分"视为"对结构分析有帮助"。考试中**更稳的认知是 XRF 不是结构表征手段**。

### 2.7 力学与结构性能测试

- **拉伸试验**：拉伸强度、屈服强度、断裂伸长率、弹性模量。
- **硬度**：布氏、洛氏、维氏、显微硬度（维氏也用于脆性材料如玻璃）。
- **冲击**：夏比、艾氏（韧性评估）。
- **蠕变 / 疲劳**：高温长时载荷 / 循环载荷。
- **DMA**：粘弹性表征。

### 2.8 失效分析与物理量选择

> [!important] 断裂判据
> **判断断裂的正确物理量是应力 / 应变**，不是位移或力本身。
> - **脆性断裂** → 看最大主应力 / 拉应力。
> - **塑性 / 延性断裂** → 看等效应变 / von Mises 应力。
> - **疲劳** → 看应力幅 / 应变幅（S-N / ε-N 曲线）。

### 2.11 透镜间距控制与镜组装配

#### 2.11.1 间距控制方法对比（Q5）

| 方法 | 原理 | 精度 | 常用性 |
|------|------|------|-------|
| **镜座上阶梯状台肩** | 加工出阶梯面，镜片端面贴合 | 高（取决于加工） | ★★★ 常用 |
| **镜片凸起台肩**（镜座上凸起台肩） | 镜片自身磨出阶梯 / 镜座局部凸起 | 高 | ★★ 较常用 |
| **隔圈 Spacer Ring** | 金属/塑料环垫于两镜片之间 | **高**（磨削隔圈可达 μm） | ★★★ 最常用 |
| **弹性垫圈** | 弹簧片/波形垫圈轴向压紧 | **低**（受预紧力波动） | 不能精确控距 |

> [!danger] 题目 Q5 原文答案 = 隔圈（D）
> 题干中文有错别字（"⻅法"应为"见法"），参考解析将**隔圈**判为"不能有效控制"。
> **但工程实务中**：
> - 隔圈是**最主流**的透镜间距控制件（相机镜头、显微物镜必有）；
> - 真正"不能精确控距"的是**弹性垫圈**（B 选项）。
>
> 按题干答案记"D"；按工程真实：记"弹性垫圈"。

#### 2.11.2 望远镜结构变形对策（Q20）

| 方法 | 有效性 |
|------|-------|
| 光学铰链系统 | ✅ |
| **五角反射镜**代替普通反射镜 | ✅（保持 90° 偏转不受转角影响） |
| 配重补偿技术 | ✅ |
| **五角棱镜**代替普通反射镜 | ✗（与普通镜无本质差别，仍受结构变形） |

> [!note] 区分
> - **五角反射镜 Penta Mirror**：无论输入角如何变化，输出恒 90°，可补偿镜架变形。
> - **五角棱镜 Penta Prism**：几何原理相同，但**不是题目要求的结构变形解决方案**。

### 2.12 光学薄膜与真空镀膜

#### 2.12.1 真空镀膜机的构成（Q13、Q29、Q32）

| 子系统 | 作用 | 是否核心 |
|-------|------|---------|
| **真空系统** | 机械泵 + 扩散泵/分子泵 维持高真空 | ✅ |
| **热蒸发系统** | 电阻 / 电子束 加热镀膜材料 | ✅ |
| **膜厚控制系统** | 石英晶振 / 光电法 实时测厚 | ✅ |
| 清洗系统 | 基底前处理 | **✗ 非核心**（Q29、Q32） |

> [!warning] Q13 vs Q29/Q32
> - Q13："以上全是" = 真空 + 热蒸发 + 膜厚控制（不含清洗）→ **C**
> - Q29 / Q32：在选项出现"清洗系统"时，**不选清洗**。

#### 2.12.2 增透膜打底层（Q27）

- **SiO₂**：折射率 ~1.46，**低折射率**，是典型打底层（减反）。
- Si₃N₄：n ≈ 2.0 高折射，不适合打底。
- TiO₂ / Ti₃O₅：高折射率，用作高折射层，不是打底层。

#### 2.12.3 增透膜原理速记

反射率 R = ((n₀ - n_f) / (n₀ + n_f))²；低 n_f 膜 + λ/4 厚度 → 减反增透。

### 2.14 过程能力指数（CPK）

- **CPK** = Process Capability Index = **过程能力指数**（Q18、Q25 答案）。
- **PPK** = Process Performance Index = 过程性能指数。
- 区别：
  - **CPK** 用组内标准差 σ_within，反映**短期**能力；
  - **PPK** 用总体标准差 σ_overall，反映**长期**表现。
- 公式：CPK = min(Cpu, Cpl) = min((USL-μ)/3σ, (μ-LSL)/3σ)。
- 经验基准：
  - CPK ≥ 1.33 → 合格
  - CPK ≥ 1.67 → 优秀
  - CPK < 1.0 → 工序不合格

> [!note] 其他相关
> - **精密度**（Precision）≠ CPK，它是多次重复测量一致性。
> - **精准度**（Accuracy）≠ CPK，它是与真值接近程度。
