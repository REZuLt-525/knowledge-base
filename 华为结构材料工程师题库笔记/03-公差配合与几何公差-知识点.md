## 📋 Part 1 · 知识点速览

### 1. 基本概念（7 条）
- **公称尺寸（基本尺寸）**：设计给定的尺寸，由强度/刚度/工艺/经济性确定。
- **极限尺寸**：允许尺寸变化的两个界限值（上/下极限尺寸）。
- **局部实际尺寸**：测量得到的零件实际尺寸；合格条件 **上极限尺寸 ≥ 局部尺寸 ≥ 下极限尺寸**。
- **公差**：允许尺寸的变动量，恒为正值。
- **基本偏差**：确定公差带相对零线位置的那个极限偏差。
- **公差带**：由 **标准公差（大小）+ 基本偏差（位置）** 共同确定。
- **最大/最小极限尺寸 与 基本尺寸** 的关系：**不确定**，可大于/等于/小于。

### 2. 标准公差体系（4 条）
- 国标规定共 **20 个标准公差等级**：IT01、IT0、IT1 ~ IT18。
- 数字越大，公差越大，精度越低。
- **精密仪器与重要机器主要配合**：选 IT1~IT7。
- **研磨加工**：典型公差等级 **IT01~IT5**。

### 3. 一般公差等级（GB/T 1804-2000）（1 条）
- 一般公差分为 **f（精密）→ m（中等）→ c（粗糙）→ v（最粗）**，f 精度最高。

### 4. 配合类型（6 条）
- **间隙配合**：孔 > 轴，用于有相对运动的部件（如 H7/g6）。
- **过盈配合**：轴 > 孔，用于紧固连接，不允许相对运动（如 H7/n6）。
- **过渡配合**：可能间隙可能过盈，用于同轴度要求高的静连接（如 H7/k6），压铆通常选过盈配合。
- 间隙配合公差带关系：**孔的公差带在轴的公差带上方**。
- 过盈配合公差带关系：孔的公差带在轴的公差带下方。
- 过渡配合公差带关系：孔与轴公差带相互交叠。

### 5. 基孔制与基轴制基本偏差字母（1 条）
- 孔的基本偏差：**A~H 为下偏差 EI（正值）**，J~ZC 为上偏差 ES。

### 6. 几何公差四大类与 14 个符号（3 条）
- **形状公差（6 项，无基准）**：直线度、平面度、圆度、圆柱度、线轮廓度、面轮廓度。
- **方向公差（3 项，需基准）**：平行度、垂直度、倾斜度。
- **位置公差（3 项，需基准）**：同轴度、对称度、位置度。
- **跳动公差（2 项，需基准）**：圆跳动、全跳动。

### 7. 几何公差要点（5 条）
- **倾斜度**属于方向公差。
- **圆柱度**属于形状公差。
- **同轴度**属于位置（定位）公差。
- **圆跳动公差来源**：主要是 **圆度 + 同轴度**（非垂直度/平面度）。
- **面轮廓度**公差带形状：与理论轮廓表面形状一致。

### 8. 公差原则（1 条）
- **四种公差原则**：独立原则、包容原则、最大实体要求（MMC）、最小实体要求（LMC）。

### 9. GD&T 修饰符号（1 条）
- 公差值后可加：**最大实体（M）、最小实体（L）、统计公差符号（SIM/ST）**；**延伸公差带** 一般不作为公差值后的修饰。

### 10. 公差框格（1 条）
- 轮廓度公差框格：**最多 3 格**（项目符号 / 公差值 / 基准符号）。

### 11. 尺寸链（5 条）
- 尺寸链必须是**封闭的环**，但不一定是线性的（可为平面/空间）。
- 尺寸链中间接得到的尺寸为 **封闭环**；装配尺寸链中，封闭环最后形成。
- 组成环按求解方法可分 **直线、平面、空间** 尺寸链。
- 组成环最少为 **2 环**（不是 3 环）。
- **封闭环的公差 = 各组成环公差之和**（极值法）。

### 12. 公差补偿（1 条）
- **Bonus Tolerance（公差补偿）**：最大实体/最小实体条件下的尺寸偏离补偿；四孔位置度典型最大允许补偿为 **1.5**。

### 13. 公差分析方法（3 条）
- **极值法（完全互换法）**：保证 100% 装配成功率，成本高。
- **统计法 / RSS / 均方根法**：适合批量生产，假设尺寸对称且在公差内。
- **蒙特卡洛法**：随机模拟，接近真实分布。

### 14. 公差分析步骤与作用（3 条）
- 分析步骤：建装配关系图 → 判增减环 → 定公差值 → 计算核实 → 不满足时综合调整（不只调精度）。
- 公差分析作用：识别潜在风险、降低成本、提高良率、降低返修率。
- 公差分析目标尺寸来源：**DFM（面向制造）+ DFA（面向装配）**（DFE/DFR 通常不直接来源）。

### 15. 基准体系（4 条）
- **设计基准**：设计时确定零件尺寸/形位的基准。
- **定位基准**（加工基准）：加工时确定工件在机床/夹具中位置的基准。
- **测量基准**：测量时依据的基准。
- **装配基准**：装配时确定零件在产品中相对位置的基准。

### 16. 基准标注原则（3 条）
- 标注基准应与加工基准、检验基准尽量统一。
- 基准应稳定、无斜度、便于测量和加工。
- **模具拔模面**带斜度，不适合作为基准。

### 17. 模块化设计（1 条）
- 模块化设计主要提升可维护性、可扩展性、生产效率，**并不必然提高产品性能**。

## 📖 Part 2 · 深度解说

### 一、基本概念

#### 1.1 公称尺寸（基本尺寸）

**公称尺寸**是设计给定的尺寸，根据零件的使用要求、强度、刚度等计算得出，并考虑工艺性、经济性等因素后确定。它是图纸上标注的"理想"尺寸，实际加工时必然存在偏差。

- 公称尺寸 ≠ 实际尺寸（测量得到的值）
- 公称尺寸 ≠ 极限尺寸（允许的最大/最小界限）
- 最大极限尺寸、最小极限尺寸与基本尺寸的大小关系 **不确定**——取决于基本偏差的正负。

> [!warning] 易错
> 不要认为最大极限尺寸一定大于基本尺寸。例如，对于孔 φ30h7（上偏差 0，下偏差 −0.021），最大极限尺寸 = 基本尺寸；对于某些带负偏差的轴，最大极限尺寸可能小于基本尺寸。

*相关题号：Q31、Q50*

#### 1.2 极限尺寸与局部尺寸

**上极限尺寸**和 **下极限尺寸** 是允许尺寸变动的两个边界值，**局部实际尺寸** 是实际测量结果。

合格零件的判定公式：

$$ D_{max} \geq D_{actual} \geq D_{min} $$

即 **上极限尺寸 ≥ 局部尺寸 ≥ 下极限尺寸**（含等号）。

*相关题号：Q20*

#### 1.3 基本偏差与公差带

- **基本偏差**：确定公差带相对于零线位置的那个极限偏差，可为上偏差或下偏差。
- **公差带**：由两大要素构成
  1. **标准公差** —— 决定公差带的大小（宽度）
  2. **基本偏差** —— 决定公差带相对零线的位置（高度）
- 孔的基本偏差字母 **A~H 为下偏差（EI，正值）**，J~ZC 为上偏差（ES）。
- 轴的基本偏差字母 a~h 为上偏差（es），j~zc 为下偏差（ei）。

> [!warning] 易错
> 极限尺寸、加工公差不是公差带的"基本要素"，它们是通过基本尺寸 + 标准公差 + 基本偏差计算得来的派生量。

*相关题号：Q9、Q30*

### 二、标准公差体系

#### 2.1 20 个标准公差等级

国标规定的标准公差等级共 **20 个**：

| 代号 | IT01 | IT0 | IT1 | IT2 | ... | IT18 |
|------|------|-----|-----|-----|-----|------|
| 精度 | 最高 | → | → | → | → | 最低 |
| 公差值 | 最小 | → | → | → | → | 最大 |

- 数字越大，公差值越大，制造精度越低，成本越低。
- 等级选择原则：**在保证使用要求的前提下，尽量选择较低（粗）的公差等级，以降低成本**。

#### 2.2 等级选择经验

| 应用场景 | 推荐 IT 等级 |
|----------|--------------|
| 量规、精密标准件 | IT01 ~ IT1 |
| 精密仪器、重要机器主要配合 | IT1 ~ IT7 |
| 一般机器配合 | IT6 ~ IT11 |
| 研磨加工可达精度 | IT01 ~ IT5 |
| 自由公差（非配合尺寸） | IT12 ~ IT18 |

*相关题号：Q3、Q4、Q21、Q44*

#### 2.3 GB/T 1804-2000 一般公差等级

一般公差（线性尺寸的未注公差）分为四个等级：

| 代号 | 含义 | 精度 |
|------|------|------|
| **f** | 精密级 | **最高** |
| **m** | 中等级 | 中 |
| **c** | 粗糙级 | 较低 |
| **v** | 最粗级 | 最低 |

> [!warning] 易错
> 一般公差的字母顺序容易记反。记忆口诀：**"f 精 m 中 c 粗 v 最粗"**，或按英文 fine / medium / coarse / very-coarse 记。

*相关题号：Q10、Q28、Q55*

### 三、配合类型

#### 3.1 三种配合对比表

| 配合类型     | 定义              | 孔轴尺寸关系 | 公差带位置关系          | 适用场景              | 推荐实例                         |
| -------- | --------------- | ------ | ---------------- | ----------------- | ---------------------------- |
| **间隙配合** | 具有间隙（含最小间隙 = 0） | 孔 > 轴  | 孔公差带在轴公差带 **上方** | 有相对运动的部件、轴承游动、导向件 | **H7/g6**、H8/f7、H9/d9        |
| **过盈配合** | 具有过盈            | 轴 > 孔  | 孔公差带在轴公差带 **下方** | 紧固连接、不允许相对运动、压铆   | **H7/n6**（过渡偏过盈）、H7/p6、H7/s6 |
| **过渡配合** | 可能间隙也可能过盈       | 视实际尺寸  | 孔与轴公差带 **交叠**    | 同轴度要求高但需拆装的连接     | **H7/k6**、H7/m6              |

> [!warning] 易错
> H7/n6 在《公差与配合》国家标准里归类为 **过渡配合**（可能过盈也可能间隙），但 Q18 原题解析将其视为 **过盈配合**（实际最大过盈大于最大间隙时偏向过盈）。考试以题目解析为准。

#### 3.2 典型配合字母标识

- **基孔制**：孔的基本偏差固定为 H（下偏差 EI = 0），通过改变轴的基本偏差字母来形成不同配合。
  - 间隙配合：H/a ~ H/h
  - 过渡配合：H/j ~ H/n
  - 过盈配合：H/p ~ H/zc
- **基轴制**：轴的基本偏差固定为 h（上偏差 es = 0），通过改变孔的基本偏差。

#### 3.3 间隙配合的公差带图示

```
上偏差 ───────────
       ┌──孔公差带──┐   ← 孔公差带整体在零线之上或与零线接触
────── │           │ ─────────── 零线 (基本尺寸)
       └───────────┘
       ┌──轴公差带──┐   ← 轴公差带整体在孔公差带之下
下偏差 └───────────┘
```

*相关题号：Q1、Q2、Q18、Q29、Q46、Q53、Q56、Q65*

### 四、几何公差分类与符号

#### 4.1 14 种几何公差符号对照表

| 分类 | 项目 | 符号 | 是否需基准 | 控制内容 |
|------|------|------|------------|----------|
| **形状公差** | 直线度 | ─ | 否 | 实际直线对理想直线的变动量 |
|  | 平面度 | ▱ | 否 | 实际平面对理想平面的变动量 |
|  | 圆度 | ○ | 否 | 同一正截面实际圆对理想圆的变动量 |
|  | 圆柱度 | ⌭ | 否 | 圆柱面所有截面的综合形状误差 |
|  | 线轮廓度 | ⌒ | 可选 | 实际曲线对理想曲线的变动量 |
|  | 面轮廓度 | ⌓ | 可选 | 实际曲面对理想曲面的变动量（公差带与理论轮廓形状一致） |
| **方向公差** | 平行度 | ∥ | 是 | 被测要素对基准的平行程度 |
|  | 垂直度 | ⊥ | 是 | 被测要素对基准的垂直程度 |
|  | 倾斜度 | ∠ | 是 | 被测要素对基准的指定角度偏差 |
| **位置公差** | 位置度 | ⌖ | 是 | 被测要素对理想位置的偏离 |
|  | 同轴度 | ◎ | 是 | 被测轴线对基准轴线的偏离 |
|  | 对称度 | ⌯ | 是 | 被测中心平面对基准中心平面的偏离 |
| **跳动公差** | 圆跳动 | ↗ | 是 | 绕基准轴线回转一周的跳动量 |
|  | 全跳动 | ⌰ | 是 | 绕基准轴线连续回转的跳动量 |

> [!warning] 易错
> - 线/面轮廓度在有基准时是 **方向/位置公差**，无基准时是 **形状公差**，属于"两栖"项目。
> - **倾斜度**属于方向公差（非形状公差）。
> - **圆柱度**属于形状公差（非位置或跳动公差）。
> - **同轴度**属于位置（定位）公差（非跳动公差）。

*相关题号：Q6、Q8、Q16、Q25、Q26、Q34、Q35、Q39、Q40、Q42、Q47、Q51、Q52、Q54、Q57、Q58、Q60*

#### 4.2 形状公差（无需基准）

形状公差是 **单一实际要素的形状所允许的变动全量**，仅描述零件本身某要素的形状好坏，与外部基准无关。

典型形状公差项目：
- **直线度**：控制直线（轴线、棱边）形状偏差
- **平面度**：控制平面形状偏差，常用 **三次元 CMM** 检测
- **圆度**：控制回转体横截面圆的形状偏差
- **圆柱度**：综合控制圆柱面在横截面和轴截面内的形状误差
- **线轮廓度**：控制曲线轮廓的形状
- **面轮廓度**：控制曲面轮廓的形状；**公差带形状与理论轮廓表面的形状一致**

> [!warning] 易错
> 平面度公差**不需要基准**，只关注自身平面的平整情况，不需要跟其他平面保持方向或位置要求。**与尺寸公差可以是独立的，也可能有关联**。

*相关题号：Q6、Q16、Q25、Q26、Q35、Q40、Q42、Q51、Q52、Q57、Q58*

#### 4.3 方向公差（需要基准）

方向公差是 **关联实际要素对基准在方向上允许的变动全量**，控制被测要素相对于基准的 **角度关系**。

| 项目 | 被测与基准的角度 | 典型应用 |
|------|------------------|----------|
| 平行度 | 0° | 两个相对平行的平面/轴 |
| 垂直度 | 90° | 直角配合 |
| 倾斜度 | 0° ~ 90° 任意角 | 斜面、锥面 |

#### 4.4 位置公差（需要基准）

位置公差是 **关联实际要素的位置对基准所允许的变动全量**，控制的是 **位置关系**。

- **同轴度**：控制被测轴线对基准轴线的偏离（如轴类零件两段轴共线）
- **对称度**：控制中心平面/中心线的对中
- **位置度**：控制点、线、面对理论位置的偏离（常用于孔组）

#### 4.5 跳动公差（需要基准）

跳动公差是 **关联实际要素绕基准轴线回转一周或连续回转时所允许的最大跳动量**。

- **圆跳动**：单个截面旋转一周的跳动
- **全跳动**：连续回转的最大跳动量
- **跳动公差来源**：**圆度 + 同轴度**（圆度差导致回转跳动，同轴度偏差导致轴偏心跳动）
- 跳动公差主要用于控制 **旋转要素的径向或轴向偏移**

> [!warning] 易错
> 跳动公差的误差来源是 **圆度 + 同轴度**。垂直度、平面度通常不直接导致圆跳动。

*相关题号：Q34、Q39、Q60*

### 五、基准体系

#### 5.1 四种基准概念

| 基准类型 | 使用场合 | 定义 |
|----------|----------|------|
| **设计基准** | 设计阶段 | 设计零件时所采用的基准，用于确定零件的尺寸、形状和位置 |
| **定位基准**（加工基准） | 加工阶段 | 工件在机床或夹具中装夹时，用来确定加工表面相对于刀具切削位置的面 |
| **测量基准** | 检验阶段 | 测量时所依据的基准，用于确定被测量尺寸、形状和位置 |
| **装配基准** | 装配阶段 | 装配时用于确定零件或部件在产品中相对位置的基准 |

工艺基准是一个上位概念，包括工序基准、定位基准、测量基准、装配基准。

#### 5.2 尺寸标注基准选择原则

正确的标注原则：
1. 尺寸的标注基准和 **加工基准** 尽量统一
2. 尺寸的标注基准和 **检验基准** 尽量统一
3. 尺寸的标注基准 **尽量统一**（一个零件尽量少用多个基准）

错误原则：
- ❌ 零件的周边均可作为基准随意进行尺寸标注（会导致混乱）

#### 5.3 基准面选择

适合作为基准的面：稳定、无斜度、便于测量和加工。
- ✅ 零件装配面
- ✅ 加工夹持面
- ✅ 检具贴合面
- ❌ **模具拔模面**（带斜度，位置尺寸不固定）

> [!warning] 易错
> 模具拔模面为便于脱模带有斜度，**不适合**作为图纸标注基准。

*相关题号：Q19、Q32、Q38、Q49、Q61*

### 六、公差原则

#### 6.1 四种公差原则

| 原则 | 符号 | 核心含义 |
|------|------|----------|
| **独立原则** | （默认） | 尺寸公差与形位公差**相互独立**，分别满足要求 |
| **包容原则** | Ⓔ | 实际要素不得超越最大实体边界，且局部实际尺寸不得超越最小实体尺寸 |
| **最大实体要求** | Ⓜ | 实际轮廓应遵守最大实体实效边界；偏离 MMC 时形位误差可超出规定值（获得补偿） |
| **最小实体要求** | Ⓛ | 实际轮廓应遵守最小实体实效边界；偏离 LMC 时形位误差可超出规定值 |

#### 6.2 公差补偿（Bonus Tolerance）

当采用 MMC 或 LMC 要求时，当零件实际尺寸偏离最大/最小实体尺寸时，**允许形位公差获得补偿**，使得加工更具经济性。

- 典型题目：**四个孔的位置度最大允许公差补偿 = 1.5**。
- 补偿机制：实际尺寸越偏离 MMC/LMC 边界，位置公差允许值越大。

*相关题号：Q11、Q27*

### 七、公差框格与 GD&T 标注

#### 7.1 公差框格基本组成

轮廓度公差框格 **最多 3 格**：

| 第 1 格 | 第 2 格 | 第 3 格 |
|---------|---------|---------|
| 公差项目符号 | 公差值 | 基准符号 |

对于方向/位置/跳动等需要多基准的公差，框格可扩展为 4 格或 5 格（第 1 基准 / 第 2 基准 / 第 3 基准）。

#### 7.2 GD&T 公差值后可加修饰符号

| 可加 | 符号 | 含义 |
|------|------|------|
| ✅ **最大实体（MMC）** | Ⓜ | 最大实体状态下公差 |
| ✅ **最小实体（LMC）** | Ⓛ | 最小实体状态下公差 |
| ✅ **统计公差符号** | ST | 公差按统计方法分配 |
| ❌ 延伸公差带 | Ⓟ | 作用于特定位置（一般在基准或要素上），不作为公差值后的修饰 |

> [!warning] 易错
> "延伸公差带"主要用于螺纹连接等对公差带延伸的情况，通常不在公差值后增加特定的优势符号。

*相关题号：Q17、Q58、Q64、Q66*

### 八、尺寸链

#### 8.1 尺寸链定义与特征

**尺寸链**：在零件加工或机器装配过程中，由互相联系的尺寸按一定顺序首尾相接排列而成的 **封闭尺寸组**。

核心特征：
1. ✅ 尺寸链中的环 **相互关联**
2. ✅ 尺寸链必须是 **封闭的**
3. ❌ 尺寸链 **不一定线性**（可为平面、空间尺寸链）
4. ✅ 装配尺寸链中 **封闭环最后形成**（精度由其他组成环决定）

#### 8.2 尺寸链环的分类

| 环类型 | 含义 | 特征 |
|--------|------|------|
| **封闭环** | 间接得到的尺寸（装配中最后形成） | 一个尺寸链仅 1 个封闭环 |
| **增环** | 与封闭环同向变动 | 该环增大 → 封闭环增大 |
| **减环** | 与封闭环反向变动 | 该环增大 → 封闭环减小 |
| **补偿环** | 用于调整装配精度 | 常见于可调装配 |

#### 8.3 尺寸链分类（按求解方法）

- **直线尺寸链**：所有环在同一直线上
- **平面尺寸链**：所有环在同一平面内
- **空间尺寸链**：环在三维空间内

#### 8.4 尺寸链设计原则

- **组成环数目越少越好**（简化计算、减小累计误差）
- 组成尺寸链的环数最少为 **2 环**
- 封闭环的公差 = 各组成环公差之和（极值法公式）：

$$ T_{封闭} = \sum_{i=1}^{n} T_i $$

> [!warning] 易错
> - 组成尺寸链的环数最少为 **2 环**，不是 3 环。
> - 尺寸链 **可以同时存在增环、减环和封闭环**。
> - 即使公式计算出错，并不意味尺寸链无法闭环，可能只是人为错误。
> - 尺寸链 **可以通过结构设计改良**，并非不可改变。

*相关题号：Q12、Q13、Q22、Q43、Q59*

### 九、公差分析方法

#### 9.1 三种公差分析方法对比表

| 方法 | 原理 | 计算公式（封闭环） | 成本 | 装配成功率 | 适用场合 |
|------|------|---------------------|------|-----------|----------|
| **极值法**（完全互换法） | 所有组成环同时取极限 | $ T = \sum T_i $ | **高** | **100%** | 单件小批、高可靠性要求、环数少 |
| **统计法 / RSS（均方根法）** | 概率加权，假设尺寸对称且在公差内 | $ T = \sqrt{\sum T_i^2} $ | 中 | < 100%（约 99.73%） | 批量生产、环数多 |
| **蒙特卡洛法** | 随机数模拟真实尺寸分布 | 仿真抽样 | 中~低 | 接近真实 | 复杂尺寸链、非对称公差、非正态分布 |

#### 9.2 极值法（完全互换法）要点

- 将每个组成环的公差取到极限值（正负最大）
- **保证 100% 装配成功率**，无不合格品
- 但要求严格，**成本高**
- 常用于环数少、精度要求极高的场合
- **注意**：并非所有高精度（如航空航天）场合都用极值法，为了降低成本常结合概率法

> [!warning] 易错
> "极值法用于航空航天等高精度领域" 的说法 **错误**。虽然极值法属于完全互换法，但由于其过于严格导致成本过高，航空航天领域也常采用概率法等更经济的方法来平衡精度与成本。

#### 9.3 统计法 / 均方根法（RSS）要点

- 假设所有尺寸都在公差范围之内
- 假设尺寸都是 **对称公差**
- 基于正态分布，封闭环公差按平方和开方合成
- 优点：
  - ✅ 成本较低
  - ✅ 产品较容易设计
  - ✅ 接近真实性
- 缺点：
  - ❌ **不能保证不会有不合格品产生**
  - ❌ 对大批量生产并非特别适合（大批量多用蒙特卡洛）

#### 9.4 蒙特卡洛法要点

- 通过随机抽样模拟大量装配过程
- 可处理非正态分布、非对称公差
- 结果接近真实生产情况
- 属于 **随机累加法**、**统计实验法**

#### 9.5 公差链分析方法（题目汇总）

公差链分析的主要方法：
- ✅ **随机累加法**（蒙特卡洛类）
- ✅ **统计实验法**（RSS 类）
- ✅ **极值法**
- ❌ 排序法（不是公差链分析的典型方法）

*相关题号：Q7、Q14、Q23、Q45、Q62、Q63*

### 十、公差分析步骤与作用

#### 10.1 公差分析步骤

正确的分析步骤：
1. **建立装配关系图**：确保尺寸链上所有零件都在装配关系图上，且各组成环的配合无误
2. **判增减环**：确定每个零件在尺寸链上的变化对整个向量的变化影响是增环还是减环
3. **定义公差值**：根据公差设计规范和供应商加工能力要求定义每个零件的公差值
4. **核实满足要求**：核实设计的公差是否满足公差技术规范要求
5. **综合调整**：不满足时综合调整——改变设计、选择不同加工工艺、优化装配方法等

> [!warning] 易错
> 当公差分析结果不满足要求时，**不能仅通过调整尺寸链精度** 来使其满足。还可以：
> - 改变零件的设计
> - 选择不同的加工工艺
> - 优化装配方法
> - 调整装配基准

#### 10.2 公差分析的作用

公差分析的四大作用：
1. ✅ **提前识别潜在风险**（零部件配合不良、功能失效等）
2. ✅ **降低成本**（避免过度加工和过高精度要求）
3. ✅ **提高产品良率**（合理公差保证更多产品合格）
4. ✅ **降低产品返修率**（初次装配就达到较好质量）

#### 10.3 公差分析目标尺寸来源

公差分析的目标尺寸主要来源于：
- ✅ **DFM（Design for Manufacturability，面向制造的设计）**
- ✅ **DFA（Design for Assembly，面向装配的设计）**
- ✅ **DFR（Design for Reliability，面向可靠性的设计）**（Q41 认可）
- ❌ DFE（Design for Environment，面向环境的设计）—— 关注环保，通常不是直接来源

> [!warning] 易错
> 不同题目对 DFR 是否为公差分析目标尺寸来源的结论不一致：
> - Q33、Q37 认为 **仅 DFA + DFM**
> - Q41 认为 **DFA + DFM + DFR**
> 考试中以题目解析为准，核心来源是 **DFA 和 DFM**。

#### 10.4 公差分析维度

- **一维**：沿直线方向的尺寸链
- **二维**：平面内的尺寸关系
- **三维**：立体空间的姿态变化（涉及 6 个自由度）

*相关题号：Q5、Q33、Q37、Q41、Q48*

### 十一、模块化设计

#### 11.1 模块化设计的正确做法

- ✅ 每个模块中的 **关键要素 / 光学件** 要相对于基准进行调校
- ✅ 重要表面以 **组装期间的基准面** 为准，设计成同心、平行或垂直表面
- ✅ 每个模块都需要有 **装配基准面**，便于定位和安装
- ✅ 通过合理设计可提高 **可维护性、可扩展性、生产效率**

#### 11.2 模块化设计的误区

> [!warning] 易错
> **模块化设计并不必然提高产品性能**。
>
> 模块化设计的主要优势在于可维护性、可扩展性、生产效率，而产品性能还受到材料、工艺、设计细节等多重因素影响，不是模块化能直接决定的。

*相关题号：Q15、Q24、Q36*
