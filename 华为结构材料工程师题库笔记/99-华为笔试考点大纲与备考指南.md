## 二、笔试大纲 · 核心考点

### 📦 模块 1：机械基础与公差配合

涵盖互换性与技术测量的基础内容：

- **形位公差**：尺寸链、公差带、配合制（基孔制 / 基轴制）
- **形位误差判断**：直线度、平面度、圆度、同轴度等基础概念
- **机械设计基础**：
  - 连接：螺纹、键、销
  - 传动：齿轮、带传动
  - 常用机构：凸轮、连杆

**推荐复习**：[[03-公差配合与几何公差-知识点]] · [[05-机械传动与机构-知识点]] · [[06-机械连接与密封-知识点]]

### 🏭 模块 2：材料与制造工艺（核心）

- **工程材料**：
  - 金属材料：碳钢、合金钢
  - 高分子材料
  - 陶瓷材料
  - 重点掌握各类材料的**基本性能**与**应用场景**
- **热处理工艺**：
  - 退火、正火、淬火、回火的原理与适用场景
  - 典型例：**再结晶退火**用于消除形变强化
- **机械加工工艺**：
  - 车、铣、刨、磨、钻的特点与适用场景
  - 表面粗糙度与加工精度对应关系
- **板料成形**：
  - 拉伸、弯曲、冲压工艺
  - 变形强化与消除方法
- **表面处理**：
  - 电镀、喷涂、阳极氧化的作用与应用

**推荐复习**：[[02-材料科学与热处理-知识点]] · [[07-加工工艺-知识点]] · [[08-表面处理与腐蚀-知识点]] · [[04-塑胶材料与注塑模具-知识点]]

### 🔧 模块 3：整机工艺与结构设计（岗位专属）⭐

这是本岗位特有的内容，重点掌握：

- **产品装配工艺**：
  - 装配精度控制（分组装配、修配法、调整法）
  - 防错设计（Poka-Yoke）
  - 工艺路线规划
- **整机可靠性**：
  - 散热设计（对流/传导/辐射）
  - 振动与冲击防护
  - 电磁兼容（EMC）基础
- **结构设计**：
  - 常用连接方式：卡扣、螺丝、焊接（对比优缺点）
  - 结构强度与刚度设计
- **生产工艺基础**：
  - SMT（表面贴装技术）
  - 焊接工艺
  - 整机组装流程
  - 工艺文件：**BOM、工艺卡**

**推荐复习**：[[14-整机工艺岗位笔试题库-知识点]] · [[10-结构强度与可靠性-知识点]] · [[06-机械连接与密封-知识点]]

### 📐 模块 4：基础力学与物理常识

- **材料力学**：
  - 应力应变
  - 拉/压/弯/扭基本概念
  - 强度与刚度条件
- **静力学**：
  - 受力分析
  - 约束反力计算
- **流体力学 / 热力学**：
  - 基础散热
  - 对流换热常识（整机散热场景）

**推荐复习**：[[01-材料力学基础-知识点]] · [[10-结构强度与可靠性-知识点]]

## 三、🔥 高频真题方向

### 1️⃣ 材料与热处理

- **对板料多次拉伸，消除形变强化应使用哪种热处理？** → **再结晶退火** ✅
- 不同材料性能对比：金属 / 塑料 / 陶瓷的优缺点与应用
- 常用热处理工艺的目的：
  - 退火 → 消除内应力、降低硬度
  - 正火 → 细化晶粒、改善切削性
  - 淬火 → 提高硬度（得马氏体）
  - 回火 → 降低脆性、消除淬火应力

### 2️⃣ 公差与配合

- 形状误差 vs 位置误差：
  - **形状误差**（无基准）：直线度、平面度、圆度、圆柱度
  - **位置误差**（需基准）：同轴度、对称度、位置度
- **基孔制 vs 基轴制**：优先基孔制
- 公差带计算与判断

### 3️⃣ 制造工艺

- 不同加工方法的**精度 / 粗糙度对比**：
  - 磨削 > 车削 > 铣削 > 钻削（精度和表面质量）
  - 磨削可达 Ra 0.4~0.8 μm
- 冲压 / 拉伸工艺缺陷：
  - **起皱**（压应力过大，法兰起皱）→ 控压边力
  - **拉裂**（拉应力过大）→ 增大圆角、改善润滑
- 表面粗糙度符号的含义与标注

### 4️⃣ 整机工艺场景题

- **装配精度控制方法**：分组装配、修配法、调整法（≠ 增加公差）
- **整机散热方式**：对流（主）、传导、辐射
- **卡扣 vs 螺丝连接对比**：

| 连接方式 | 优点 | 缺点 |
|---|---|---|
| **卡扣** | 成本低、装配快、无需工具 | 多次拆装易疲劳、强度有限 |
| **螺丝** | 可拆卸、强度可调、定位准确 | 需工具、成本高、装配慢 |
| **焊接** | 强度最高、密封好 | 不可拆卸、热影响区 |

## 四、✅ 备考建议

### 🎯 优先复习高频考点

> [!important] 必考四大块
> 1. **公差配合** → [[03-公差配合与几何公差-知识点]]
> 2. **材料热处理** → [[02-材料科学与热处理-知识点]]
> 3. **机械加工工艺** → [[07-加工工艺-知识点]]
> 4. **装配工艺** → [[14-整机工艺岗位笔试题库-知识点]]

- 形位公差的**符号**、热处理工艺的**适用场景**、加工方法的**特点**是最容易出选择题的地方
- 先把**基础概念**过一遍，再刷题巩固

### 🚫 不用花时间的内容

- 复杂电路、数字逻辑、算法题 → 整机工艺岗不考
- 深入的仿真算法细节 → 只需了解概念

### 📖 贴合岗位场景

多关注和**产品制造、装配、材料**相关的知识点：
- SMT 工艺流程
- BOM 的结构与作用
- 工艺路线规划
- 可靠性设计（散热/防振/防EMC）

### ⏱️ 考前准备

- 提前测试**设备和网络**
- 按邮件提示下载**客户端**或准备好浏览器
- 考试时间 **60 分钟**，题目量不大，控制好做题节奏
- 建议时间分配：选择题平均 **1 分钟/题**，判断题更快
