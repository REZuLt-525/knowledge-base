## Part 1 速览

### 🎯 核心速记口诀

| 主题 | 速记要点 |
| --- | --- |
| **电镀难度** | 电位越负越难镀：Mg (-2.37V) > Zn (-0.76V) > Fe (-0.44V) > Cu (+0.34V) |
| **阳极氧化** | 铝合金专用，电化学法，生成多孔氧化膜，可染色（手机中框） |
| **微弧氧化** | 铝/镁/钛合金，陶瓷化膜层更厚更硬 |
| **化学镀** | 不需外接电源、均镀好、可镀金属与非金属 |
| **高分子基材** | 能用：PVD、喷涂、化学镀、NCVM；不能用：阳极氧化、微弧氧化、电镀 |
| **镀后粗糙4因素** | 时间长、浓度大、温度高、电流密度大 |
| **牺牲阳极** | 远洋轮船锌块保护船体（Zn 电位更负先腐蚀） |
| **电偶腐蚀对策** | 缩小阴极 / 扩大阳极；绝缘垫 / 中间镀层；涂覆有机涂层 |
| **应力腐蚀经典组合** | Al+海水；奥氏体不锈钢+氯化物/高温水；黄铜+氨；碳钢+碱 |
| **湿法蚀刻侧蚀最小** | 喷淋 < 鼓泡 < 浸泡 < 泼溅 |
| **镀层的作用** | 保护、装饰、粘接、吸光；**不包括增加基材刚性** |

### 📊 常见表面处理方法对比表

| 工艺 | 原理类型 | 适用基材 | 膜层特点 | 典型用途 |
| --- | --- | --- | --- | --- |
| **电镀** | 电化学 | 导电金属 | 金属层（Ni、Cr、Zn、Cu、Au）| 防腐、导电、装饰 |
| **化学镀** | 化学还原 | 金属 + 非金属 | 均匀，复杂形状适用 | 镀Ni-P、通孔印刷板 |
| **阳极氧化** | 电化学氧化 | 铝/镁/钛合金 | 多孔氧化膜，可染色 | 手机中框、笔电外壳 |
| **微弧氧化** | 高压电化学（微弧放电） | 铝/镁/钛合金 | 陶瓷化，膜层厚、硬度高 | 耐磨件、航空结构 |
| **PVD** | 物理气相沉积 | 金属 + 高分子（低温） | 高硬度、薄膜致密 | 刀具涂层、手机装饰 |
| **CVD** | 化学气相沉积 | 耐高温金属/陶瓷 | 高温沉积、膜层厚 | 硬质合金刀具、半导体 |
| **喷砂** | 机械冲击 | 金属/玻璃 | 哑光、除鳞、清洁 | 前处理、消光 |
| **喷丸** | 机械冲击（钢丸） | 金属 | **引入压应力**，强化表面 | 抗疲劳、抗应力腐蚀 |
| **拉丝** | 机械研磨 | 金属 | 纹理装饰 | 不锈钢面板 |
| **抛光** | 机械/化学 | 金属 | 镜面 | 装饰、反射面 |
| **喷涂/喷漆** | 涂覆 | 通用 | 有机涂层 | 防腐 + 外观 |
| **粉末喷涂** | 静电喷涂 + 烘烤 | 金属 | 环保无溶剂、厚膜 | 家电、机柜 |
| **NCVM** | 不导电真空镀 | 高分子 | 金属质感但不导电 | 手机Logo、装饰 |
| **钝化/磷化/发黑** | 化学转化膜 | 不锈钢/碳钢 | 薄膜防锈 | 紧固件、黑色件 |

### 📊 PVD vs CVD 对比速查

| 项目 | PVD（物理气相沉积） | CVD（化学气相沉积） |
| --- | --- | --- |
| **基本原理** | 物理手段（溅射、蒸发、离子镀）使材料气化后沉积 | 气态反应物在基材表面发生化学反应形成薄膜 |
| **工作温度** | 较低（可低温，<500°C，甚至室温级） | 较高（通常 800–1000°C 以上） |
| **基材适用** | 金属 + 高分子（低温PVD） | 多为耐高温金属/陶瓷，不适合高分子 |
| **膜层厚度** | 较薄（μm 级） | 可较厚、沉积速率较高 |
| **膜层均匀性** | 直线性沉积，阴影效应明显 | 绕射性好，复杂形状均匀性优 |
| **典型应用** | 刀具 TiN/CrN、手机外观件、光学膜 | 硬质合金刀具涂层、半导体薄膜、金刚石涂层 |

### 📊 金属腐蚀类型对比

| 腐蚀类型 | 机理 | 典型场景 |
| --- | --- | --- |
| **化学腐蚀** | 金属与干燥气体或非电解质直接反应 | 钢在高温干燥空气中氧化 |
| **电化学腐蚀** | 金属在电解质中形成原电池 | 钢件在潮湿环境生锈 |
| **应力腐蚀**（SCC）| 拉应力 + 腐蚀介质协同开裂 | 奥氏体不锈钢在含氯环境开裂 |
| **电偶腐蚀**（接触腐蚀）| 两种电位不同的金属接触 + 电解液 | Al 件与不锈钢螺钉接触腐蚀 |
| **晶间腐蚀** | 晶界优先腐蚀（贫铬等）| 敏化态不锈钢焊缝两侧 |
| **点蚀/孔蚀** | 局部钝化膜破坏形成小孔 | 不锈钢在含 Cl⁻ 环境 |
| **缝隙腐蚀** | 缝隙内氧浓差电池 | 法兰、螺栓缝隙 |

### 📊 电偶腐蚀敏感金属组合示例

| 阳极（优先腐蚀）| 阴极（受保护）| 环境 |
| --- | --- | --- |
| 镁 Mg | 铝、钢、铜 | 海水/潮湿空气 |
| 锌 Zn | 碳钢（→镀锌钢） | 大气/海水（故做牺牲阳极）|
| 铝 Al | 不锈钢、铜 | 海水/湿大气 |
| 碳钢 | 不锈钢、铜、钛 | 湿大气、海水 |
| 铜 Cu | 银、金 | 电子环境 |

> 口诀：**电位越负 = 越活泼 = 越容易做阳极被腐蚀 = 可做牺牲阳极**。

## Part 2 深度解说

### 1. 表面处理的目的与分类

#### 1.1 表面处理的主要目的

| 目的 | 说明 | 典型工艺 |
| --- | --- | --- |
| **装饰** | 赋予外观（颜色、纹理、光泽） | 阳极氧化染色、喷涂、拉丝、NCVM |
| **耐蚀** | 阻隔腐蚀介质 / 牺牲阳极 / 钝化 | 电镀Zn、磷化、钝化、喷漆 |
| **耐磨** | 提高硬度、降低磨损 | 镀Cr、PVD TiN、阳极氧化硬膜 |
| **改善物理性能** | 导电、导热、光学（吸光）、粘接前处理 | 镀Au（导电）、黑色镀层（吸杂散光）、粗化（粘接）|

> [!tip] 光机结构镀层的作用（Q6/Q13 高频考点）
> 镀层典型作用包括：① **保护零件**；② **增加粘接可靠性**；③ **吸收杂散光**（黑色镀层/阳极氧化黑）。
> **镀层一般不能增加基材刚性**——刚性由基材本身的材料与结构决定，薄薄几微米的镀层贡献可忽略。

#### 1.2 按作用机理分类

- **化学法**：钝化、磷化、发黑、化学镀、化学氧化
- **电化学法**：电镀、阳极氧化、微弧氧化、电解抛光
- **物理法**：PVD、喷涂、热喷涂、机械加工（喷砂/抛光/拉丝/喷丸/滚压）
- **化学气相法**：CVD
- **装饰/标识**：丝印、移印、激光打标、IMD/IML、NCVM

---

### 2. 化学处理

#### 2.1 钝化

- **原理**：在金属表面形成稳定的薄氧化膜（通常含 Cr₂O₃），使金属由活化态转入钝态。
- **常用对象**：不锈钢、铝、铜。
- **钝化剂**：铬酸、硝酸、柠檬酸（环保趋势下用柠檬酸替代铬酸）。

#### 2.2 磷化

- **原理**：金属与磷酸盐溶液反应生成不溶性磷酸盐转化膜（锌系、锰系、铁系）。
- **作用**：提高耐蚀性、作为涂装前处理提高附着力、减摩（冷加工前处理）。
- **常用对象**：碳钢、低合金钢。

#### 2.3 发黑（氧化）

- **原理**：碱性氧化法在钢件表面生成 Fe₃O₄ 黑色氧化膜。
- **特点**：膜薄、不改变尺寸、耐蚀有限，通常需浸油后使用。
- **用途**：枪械、工具、紧固件的装饰防锈。

---

### 3. 电化学处理

#### 3.1 电镀

**原理**：在电解液中以工件为阴极，通直流电，使镀层金属离子在工件表面还原沉积。

**常见镀层**：

| 镀层 | 主要作用 |
| --- | --- |
| 镀 Zn | 牺牲阳极保护碳钢（最常见防锈镀层） |
| 镀 Ni | 中间镀层、防护装饰 |
| 镀 Cr（装饰/硬铬） | 装饰性/耐磨耐蚀 |
| 镀 Cu | 中间层、导电 |
| 镀 Au/Ag | 电子接触件（导电、抗氧化） |
| 镀 Sn | 可焊性、食品包装 |

**电极电位与电镀难度（Q1 / Q7 / Q14 重复出现4次）**：

> **电极电位越负的金属，越活泼、越难作为镀层电镀。**

| 金属 | 标准电极电位 E° | 电镀难易 |
| --- | --- | --- |
| Mg | **-2.37 V** | **最难**（几乎无法在水溶液中电镀）|
| Al | -1.66 V | 非常难（需用熔盐电镀）|
| Zn | -0.76 V | 较易 |
| Fe | -0.44 V | 易 |
| Cu | +0.34 V | 很易 |
| Ag | +0.80 V | 非常易 |
| Au | +1.50 V | 最易 |

> 原因：电位越负的金属氢析出电位相对更低，电镀时水会优先被还原（析氢），无法在水溶液中稳定沉积该金属，因此 Mg、Al 必须在**非水熔盐体系**下才能电镀。

#### 3.2 电镀后表面变粗糙的原因（Q15 四选全对）

从电镀工艺角度，以下四个因素均会使镀层结晶变粗、表面变粗糙：

| 因素 | 机理 |
| --- | --- |
| **电镀时间过长** | 镀层过度生长，晶体二次长大形成粗大颗粒 |
| **镀液浓度过大** | 离子扩散快、沉积过快，结晶来不及有序排列 |
| **镀液温度过高** | 结晶速度失控，且添加剂（整平剂/光亮剂）热分解失效 |
| **电流密度过大** | 阴极附近离子浓度骤降，烧焦/树枝晶、针尖放电 |

> [!tip] 记忆技巧
> 四个"过"字口诀：**时间过长、浓度过大、温度过高、电流过大**——一起导致**结晶失控**。

#### 3.3 化学镀（Q5）

**原理**：不使用外加电源，依靠镀液中的还原剂（如次磷酸钠）将金属离子还原沉积在工件表面。

**特点**：

| 特点 | 说明 |
| --- | --- |
| 不需外接电源 | 自催化反应 |
| **均镀能力好** | 镀层厚度均匀，对复杂形状、盲孔、深孔都能均匀镀上 |
| **可镀金属与非金属** | 非金属（塑料、陶瓷）需先经粗化、敏化、活化 |
| 镀层可为合金 | 如 Ni-P（非晶态合金）、Ni-B，耐磨耐蚀 |

#### 3.4 阳极氧化

- **原理**：工件作**阳极**，在电解液（常用 H₂SO₄）中电解，表面生成多孔 Al₂O₃ 氧化膜。
- **适用基材**：**铝及铝合金**（也可对镁、钛），**不适用于高分子材料**。
- **特点**：膜层多孔 → 可染色、可封孔；硬度高；绝缘。
- **典型应用**：手机中框、笔电外壳、铝型材建筑幕墙。

#### 3.5 微弧氧化（MAO）

- **原理**：在阳极氧化基础上施加更高电压，局部产生微弧放电，将氧化膜瞬间**陶瓷化**。
- **特点**：膜层比阳极氧化更**厚（几十至数百 μm）**、硬度更高（可达HV1500+）、耐磨耐蚀更好。
- **适用**：铝/镁/钛合金；**不适用于高分子**。

### 4. PVD 物理气相沉积

#### 4.1 原理

通过物理方法（**溅射、蒸发、离子镀、电弧**）将靶材原子/分子气化或离化，然后在基材表面沉积成膜。

#### 4.2 特点

- 沉积温度**低**（含"低温 PVD"可低于 200°C，甚至室温级） → **可用于高分子基材**（Q2 关键）。
- 膜层薄、致密、硬度高。
- 环保，无三废。
- 直线性沉积，对复杂形状有**阴影效应**，绕射性差。

#### 4.3 常见 PVD 膜层

| 膜层 | 颜色 | 典型用途 |
| --- | --- | --- |
| TiN | 金黄 | 刀具、装饰 |
| TiCN | 玫瑰金/灰 | 刀具 |
| CrN | 银灰 | 耐磨、模具 |
| DLC（类金刚石）| 黑 | 高耐磨低摩擦 |
| TiAlN | 紫黑 | 高温刀具 |

---

### 5. CVD 化学气相沉积

#### 5.1 原理

将含有成膜元素的**气态反应物**通入反应室，在加热的基材表面发生**化学反应**生成固态薄膜，副产物随气流排出。

#### 5.2 与 PVD 的关键区别

| 对比项 | PVD | CVD |
| --- | --- | --- |
| 成膜机制 | 物理气化 + 冷凝 | 化学反应 + 沉积 |
| 温度 | 低（室温~500°C） | **高（800~1000°C+）** |
| 基材 | 金属 + 高分子（低温） | 多为耐高温金属/陶瓷 |
| 均匀性 | 直线沉积，阴影明显 | **绕射性好，均匀** |
| 厚度/速率 | 较薄 | 可更厚 |
| 应用 | 装饰、刀具、光学膜 | 硬质合金涂层、半导体、金刚石膜 |

> 考点提示：**高分子件不能做 CVD（温度太高）**，但可做低温 PVD。

### 6. 机械处理

#### 6.1 喷砂

- **原理**：高压气流携带砂粒（刚玉、玻璃珠、钢砂）冲击工件表面。
- **作用**：除锈、除氧化皮、粗化表面（为粘接/喷涂/电镀做前处理）、哑光装饰。

#### 6.2 喷丸 vs 滚压（表面强化对比）

> [!warning] 高频考点
> **喷丸强化、滚压** 均能在金属表面引入**残余压应力**，明显提高疲劳强度与抗应力腐蚀能力。

| 工艺 | 介质 | 作用机理 | 表面应力 |
| --- | --- | --- | --- |
| 喷丸（shot peening） | 高速钢丸/玻璃丸 | 塑性凹坑 | **压应力**（显著增加） |
| 滚压（roller burnishing） | 硬质滚轮 | 塑性流变、压实 | **压应力**（显著增加） |
| 喷砂 | 细砂 | 表面粗化 | 影响较小 |
| 抛光 | 抛光轮+磨料 | 微切削 | 基本无影响 |

#### 6.3 拉丝

- 在金属表面形成连续的平行纹理，兼具装饰与一定程度掩饰划痕的作用。
- 常见于不锈钢面板、铝合金外壳。

#### 6.4 抛光

- **机械抛光**：抛光轮 + 抛光膏，达到镜面。
- **电解抛光**：工件作阳极，在特定电解液中微凸起优先溶解，获得平整光亮表面。
- **化学抛光**：纯化学试剂作用。

---

### 7. 有机涂层与表面装饰

#### 7.1 有机涂层

| 工艺 | 特点 | 用途 |
| --- | --- | --- |
| **喷涂（液体漆）** | 溶剂型/水性，膜厚可控 | 汽车、家电、消费电子 |
| **粉末喷涂** | 静电 + 烘烤固化，无溶剂、环保，膜厚可达 60~100μm | 机柜、家电、自行车 |
| **电泳涂装** | 电场驱动涂料粒子沉积，均匀、耐蚀强 | 车身底漆、五金件 |

#### 7.2 表面装饰与标识

| 工艺 | 原理 | 典型应用 |
| --- | --- | --- |
| **丝印** | 丝网印刷油墨透过网版转印 | Logo、刻度 |
| **移印** | 硅胶头蘸油墨转印，适合曲面 | 按键、不规则表面 |
| **激光打标** | 激光束在材料表面烧蚀/氧化变色 | 序列号、标识、永久可追溯 |
| **IML / IMD** | 膜内嵌件注塑，把印有图案的薄膜嵌入塑料 | 家电面板、汽车内饰 |
| **NCVM**（不导电真空镀膜）| PVD 断续镀层形成金属质感但不连通 | 手机天线区Logo，兼顾外观与射频透过 |

> [!note] Q8 陷阱
> **IML 属于塑料成型/装饰工艺**（In-Mold Labeling/Decoration），**不是金属表面处理工艺**。金属常见表面工艺为阳极氧化、拉丝、抛光等。

---

### 8. 非金属基材的表面处理（Q2 核心）

> **关键判断**：基材为高分子时，凡是**依赖金属基体导电或高温**的工艺都不适用。

| 工艺 | 能否用于高分子 | 原因 |
| --- | --- | --- |
| **低温 PVD** | ✅ 可以 | 温度低，不破坏塑料 |
| **喷涂 / 喷漆** | ✅ 可以 | 通用工艺 |
| **化学镀** | ✅ 可以 | 不需导电，通过敏化活化可附着 |
| **NCVM** | ✅ 可以 | 真空镀装饰工艺 |
| **普通电镀** | ⚠️ 需先化学镀导电层后可镀（ABS 电镀） | 塑料不导电 |
| **阳极氧化** | ❌ 不可以 | 需金属基体电解氧化 |
| **微弧氧化** | ❌ 不可以 | 同上 |
| **CVD**（常规高温）| ❌ 不可以 | 温度过高熔化塑料 |

### 9. 表面处理常见缺陷

| 缺陷 | 成因 | 检测/预防 |
| --- | --- | --- |
| **孔洞（针孔）** | 镀液杂质、氢气吸附、基体夹杂 | 过滤镀液、除氢、基体清洁 |
| **裂纹** | 内应力过大、镀层脆、冷热交变 | 控制厚度、选合适工艺、退火 |
| **结合力差** | 前处理不彻底、油污/氧化层残留 | 充分除油、活化、粗化 |
| **麻点** | 镀液杂质、电流过大、气泡附着 | 搅拌、过滤、调低电流密度 |
| **起泡** | 基体渗氢、结合力差、涂层后受热膨胀 | 除氢、烘烤、改善前处理 |
| **粗糙** | 电流/温度/浓度/时间过大（见 3.2）| 工艺参数优化 |
| **色差** | 膜厚不均、染色不均、封孔不足 | 控制工艺稳定性 |

### 10. 金属腐蚀分类

#### 10.1 化学腐蚀

- 金属在**非电解质**或**干燥气体**中发生的纯化学反应，无电流参与。
- 例：高温钢氧化、金属在干燥氯气中腐蚀。

#### 10.2 电化学腐蚀

- 金属在**电解质溶液**中形成原电池，阳极区溶解，阴极区发生还原反应（通常为吸氧/析氢）。
- 例：钢在潮湿大气中生锈，是最常见的腐蚀形式。

#### 10.3 应力腐蚀（Stress Corrosion Cracking, SCC）

- **拉应力 + 特定腐蚀介质** 共同作用下的延迟开裂。
- 特征：低于屈服强度时即可开裂；裂纹垂直于拉应力方向；有明显"介质-材料匹配性"。

#### 10.4 电偶腐蚀（接触腐蚀 / 双金属腐蚀）

- 两种电位不同的金属在电解液中接触，**电位较负者加速腐蚀，电位较正者受保护**。
- 电位差越大、阴极面积越大、电解质导电性越强 → 腐蚀越严重。

#### 10.5 晶间腐蚀

- 沿金属晶界优先发生腐蚀。
- 典型：奥氏体不锈钢在 450–850°C 敏化析出 Cr₂₃C₆，导致晶界贫铬。
- 对策：选用低碳（304L/316L）或稳定化（321/347）不锈钢；固溶处理。

---

### 11. 应力腐蚀敏感组合（必背）

> [!warning] 四对经典敏感组合
> 这是考试、实际设计都要避开的"雷区"。

| 金属 | 敏感介质 | 说明 |
| --- | --- | --- |
| **铝合金**（尤其高强度 2xxx/7xxx） | 海水、含 Cl⁻ 溶液、潮湿大气 | 航空结构、海洋工程重点防护 |
| **奥氏体不锈钢**（304/316）| 含 Cl⁻ 溶液、**高温高压蒸馏水**、浓 NaOH | 核电、化工换热器高风险 |
| **黄铜（Cu-Zn）** | **氨 / 氨蒸汽**、胺类 | 俗称"**季节裂纹**"（season cracking） |
| **碳钢 / 低合金钢** | **浓碱**（NaOH、KOH）、硝酸盐 | 俗称"**碱脆（苛性脆化）**"；锅炉铆缝历史事故 |

**防护思路**：

1. 消除或降低拉应力（退火、喷丸引入压应力）；
2. 隔离/中和腐蚀介质（涂层、缓蚀剂）；
3. 选用抗 SCC 材料（如 316L、双相不锈钢、铝合金时效处理选T7系列）。

---

### 12. 电偶腐蚀与防护

#### 12.1 形成条件

1. 两种**电极电位不同**的金属直接接触；
2. 有**电解液**（水、盐雾、湿气）形成导通回路；
3. 形成原电池：电位负的金属作**阳极**加速溶解。

#### 12.2 牺牲阳极法（Q4 经典应用）

> **远洋轮船船体外挂锌块（或镁块）就是典型的"牺牲阳极阴极保护法"**：
> Zn 的电极电位（-0.76V）比 Fe（-0.44V）更负 → Zn 优先溶解，保护钢制船体。
> 需定期更换锌块；在淡水中则用镁块（锌在淡水中钝化失效）。

#### 12.3 电偶腐蚀防护措施（Q3 多选）

| 措施 | 原理 | 正确性 |
| --- | --- | --- |
| **缩小阴极面积 / 扩大阳极面积** | 降低阴极上的还原电流密度 → 降低阳极溶解速率 | ✅ |
| ~~扩大阴极 / 缩小阳极~~ | **错误方向**，会加剧阳极腐蚀（小阳极-大阴极最危险） | ❌（Q3 A项陷阱）|
| 选用中间镀层或垫片 | 选择与两种材料接触均轻微的金属做过渡 | ✅ |
| **整体涂覆有机涂层** | 隔绝电解液，阻断电化学回路 | ✅ |
| **绝缘垫 / 套管** | 机械隔离两种金属，阻断电子通路 | ✅ |
| 两种金属间涂保护层 | 阻断直接电接触 | ✅ |
| **选用电位相近金属** | 电位差 < 50 mV（室内）或 < 100 mV（室外/海洋）被认为安全 | ✅ |

#### 12.4 设计中的电位差限制经验值

| 使用环境 | 推荐最大电位差 |
| --- | --- |
| 室内干燥 | ≤ 250 mV |
| 室外/一般潮湿 | ≤ 150 mV |
| 海洋/盐雾环境 | ≤ 50 mV |

> [!tip] 记忆核心
> **"大阴极小阳极" = 加速腐蚀**；工程上要反过来做——尽量让电位负的金属（易腐蚀）面积更大，电位正的金属面积小。

## 🧪 湿法蚀刻侧蚀程度排序（Q9/Q11/Q12 共 3 次重复考）

蚀刻方式按侧蚀程度由小到大：

**喷淋 < 鼓泡 < 浸泡 < 泼溅**

| 方式 | 机理 | 侧蚀 |
| --- | --- | --- |
| **喷淋** | 定向喷射，流向可控 | **最小** ✅ |
| 鼓泡 | 气泡带动蚀刻液流动 | 中 |
| 浸泡 | 全向浸没，各方向等概率 | 较大 |
| 泼溅 | 流动不规则、不可控 | 最大 |

### 印制板（PCB）形成导电图形的常用方式（Q10）

**湿蚀刻（湿法蚀刻）** 是 PCB 铜箔蚀刻的主流工艺（典型蚀刻液：酸性 CuCl₂ / 碱性氨铜）。干蚀刻更多用于半导体晶圆，深蚀刻/浅蚀刻不是行业通用类别。
