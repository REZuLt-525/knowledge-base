# 柔性铰链 Flexure Joint

> **一句话理解**：一段薄而弯的 **弹性梁**，靠自身弯曲代替传统轴承+销轴做"关节"——没有摩擦、没有装配。

`#核心概念`

---

## 1. 什么是柔性铰链？

**柔性铰链 (Flexure Joint)** 是 **柔性机构 (Compliant Mechanism)** 的基本单元，定义是：

> 通过材料的 **弹性变形** 而非相对滑动/转动副来实现运动的机构。

经典教材：Howell 的 Handbook of Compliant Mechanisms ([[../03-参考文献/Ref-39-Howell-2013-CompliantMechanisms]])。在机器人领域早期广泛应用于 SDM Hand ([[../03-参考文献/Ref-10-Odhner-2014-SDMhand]], [[../03-参考文献/Ref-40-Dollar-2010-SDMhand]])。

---

## 2. 结构与数学

### 典型外观

```
  ┌──── segment block (硬厚块) ────┐
  │                                │
  │  ┌──────── flexure ────────┐  │    ← 薄梁 (2 mm 厚)
  │  │   薄、易弯曲               │  │
  │  └──────────────────────────┘  │
  │                                │
  └──── segment block (硬厚块) ────┘
```

**软硬交替**：厚块不弯，薄梁才弯，相当于把"关节"局部化到薄梁。

### 力学模型

对一段 flexure (宽 $b$，高 $h$，长 $l$，材料弹性模量 $E$)，弯曲刚度：
$$k_{\text{rot}} = \frac{E b h^3}{12 l}$$

**关键**：$h^3$ 决定了刚度对厚度极敏感。本论文中厚度是固定的 (2 mm)，用 **杨氏模量 $E$** (通过 3D 打印层数调节) 来控制刚度。

### 制造

论文中用 FDM 3D 打印 TPU 95A (NinjaFlex Cheetah)：
- **1 个 wall loop** → 最软
- **多层 bottom shell** → 稍硬

用三点弯曲测试获取实际 $E$ 值 (论文 Fig 5b)。

## 3. 优势 vs 传统关节

| 属性 | 柔性铰链 | 传统铰链 (轴承) |
|---|---|---|
| 零件数 | 1 (整体成型) | 多 (轴、套、O 圈) |
| 摩擦 | 零 | 有 |
| 精度 | 受限于材料疲劳 | 高 |
| 寿命 | 数十万次循环 | 百万次 |
| 成本 | 低 (可 3D 打印) | 高 |
| 可微加工 | ✅ (PCB 级) | ❌ |
| 抗污染 | ✅ | ❌ |

这也是柔性机构在微机电 (MEMS)、微创手术器械、航空航天仪器 ([[../03-参考文献/Ref-37-Kim-2019-VariableStiffness|Kim'19]]) 中的独特优势。

---

## 4. 本论文的使用方式

- **结构**：每根手指由 **多个 segment block + 多个 flexure 交替排列**，整体 3D 打印。
- **几何变量**：segment 块上方削平为梯形以减少多余扭矩 (论文 §3.2)。
- **设计空间**：每个 block (flexure 或 segment) 独立控制杨氏模量，共 22 个变量 (两指 × 11 块)。
- **优化策略**：联合优化刚度向量 $k \in \mathbb{R}^{22}$ 与抓取位姿。

**有趣发现**：大多数优化结果呈 "**硬指尖 + 软中段**"，恰似灵长类的指甲 + 柔软指腹 —— 暗示自然选择可能早已做过相同的 co-design。
