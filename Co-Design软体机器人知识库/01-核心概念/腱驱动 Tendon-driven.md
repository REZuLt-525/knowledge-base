# 腱驱动 Tendon-driven

> **一句话理解**：像"拉线木偶"一样用一根柔性绳索穿过机械结构，在远端拉动即可让整根结构弯曲——仿生自人类手指的肌腱。

`#核心概念`

---

## 1. 什么是腱驱动？

**腱驱动 (Tendon-driven)** 把电机 (或液压/气动) 放在远离关节的位置 (通常在手腕、底座)，通过 **不可伸长或低伸长** 的绳索 (tendon) 传递力到关节，拉动结构产生运动。

这一方式源自 **仿生**：人类手指本身没有马达，所有力都由前臂肌肉通过肌腱远程传递。

### 结构要素
- **腱 (tendon)**：通常是 Dyneema、不锈钢丝、Spectra 等高强度绳索。
- **waypoint**：腱穿过机体的 固定点 (本论文是软体网格里预留的顶点)。
- **滑轮/导向孔**：改变腱方向。
- **电机 + 卷筒**：提供拉力或位置控制。

---

## 2. 腱驱动的优势

| 优势 | 解释 |
|---|---|
| **远程驱动** | 电机离开末端，手指轻、惯量小 |
| **适合欠驱动** | 一根腱可驱动多关节，节省电机 |
| **柔顺兼容** | 天然与软体机器人结合 |
| **低耦合** | 反向驱动不必，可做 clutch 式控制 |

**代表设计**：
- [[../03-参考文献/Ref-10-Odhner-2014-SDMhand|SDM Hand]]：单电机驱动四指抓握。
- [[../03-参考文献/Ref-09-Bircher-2021-CageHand|Bircher'21 Cage Hand]]：通过打破接触实现复杂操作。
- [[../03-参考文献/Ref-43-Glick-2018-GeckoGripper|Glick'18 Gecko Gripper]]：腱驱动 + 壁虎粘附。

## 3. 建模：从运动学到力学

### 3.1 不可伸长约束 (精确模型)

假设腱总长不变，
$$\sum_i \| \mathbf{P}_{i+1} - \mathbf{P}_i \| = \text{const} = l_\text{actuator}$$

运动学约束强制施加后，系统是多约束优化问题。SOFA 框架 ([[../03-参考文献/Ref-41-Faure-2012-SOFA]]) 即采用这种做法。

**缺点**：运行时约束求解复杂，慢。

### 3.2 均匀张力近似 (本论文)

放弃运动学约束，改用 **所有 waypoint 上的张力大小相等** 这一假设：
$$\|T_0\| = \|T_1\| = \dots = \|T_N\| = f_T$$

且沿切向作用 (点对点投影到表面切面):
$$T_{\|S_i} = (I - \mathbf{n}_{S_i}\mathbf{n}_{S_i}^\top)\,T_i$$

**优点**：每步只需计算局部切向力，模拟快、数值稳。
**代价**：忽略腱长守恒，轻微漂移。

## 4. 均匀压力分布 ⭐ 本论文的关键改进

腱的走线对软体手指的变形影响巨大：

| 走线方式 | 结果 | 图示 |
|---|---|---|
| 距铰链等距 | 远端压力 ∝ 距离² → 指尖"卷"起来 | 论文 Fig 2b 下 |
| 均匀压力 (本文) | 所有 flexure 受力均衡 → 整根贴合 | 论文 Fig 2b 上 |

**推导** (简述，完整见 [[../00-总览/论文解读 - Co-Design of Soft Gripper|论文解读]] §3.2)：

设定弯矩 $M(l_i)$ 对距离 $l_i$ 求二阶导为常数 $c$，边界条件 $M'(L) = 0,\, M(L)=0$，解得：
$$M(l_i) = \tfrac{cL^2}{2}\left(1 - \tfrac{l_i}{L}\right)^2$$

结合 $M(l_i)=h_i T_i$ 和 $T_i = f_T$，得：
$$\boxed{h_i = H\left(1 - \tfrac{l_i}{L}\right)^2}$$

**含义**：腱 waypoint 离铰链的高度应沿距离 **二次递减**。这是首次把 Hirose 1978 的滑轮手指公式 ([[../03-参考文献/Ref-42-Hirose-1978-UniformPressure]]) 扩展到腱驱动软体手指。

## 5. 在本论文系统中的角色

- 作为 **执行器抽象**：单电机 + 单腱 = 控制所有 flexure 弯曲。
- 与 [[刚度分布 Stiffness Distribution]] 协同：腱张力恒定，实际弯曲主要由 flexure 局部刚度决定。
- 与 [[柔性铰链 Flexure Joint]] 结合：腱拉动 flexure 弯折。

电机：Dynamixel XL330。
传动：固定张力 + 位置控制 (1000 units ≈ 1/4 圈)。
