# 腱驱动 Tendon-driven

> **一句话理解**：电机产生的拉力通过 **细绳 (tendon, cable)** 沿着指定路径 (waypoints) 传递到末端结构 (软体 / 铰链)，驱动结构变形。腱本身近似 **不可伸长** + **只能受拉**，建模时需考虑路径约束和受力投影。

`#核心概念`

---

## 1. 形式化设定

### 1.1 腱路径离散化

腱由 $N+1$ 个 waypoint 组成:
$$\mathbf{P}_0, \mathbf{P}_1, ..., \mathbf{P}_N \in \mathbb{R}^3$$

**变量含义**：
- $\mathbf{P}_0$ — 电机端 waypoint (起点)。
- $\mathbf{P}_N$ — 指尖固定点 (终点)。
- 中间 $\mathbf{P}_1, ..., \mathbf{P}_{N-1}$ — 腱穿过软体的过孔点。
- 每段是 **直线** $[\mathbf{P}_i, \mathbf{P}_{i+1}]$。

腱的总长度:
$$L_\text{tendon} = \sum_{i=0}^{N-1} \|\mathbf{P}_{i+1} - \mathbf{P}_i\|$$

**变量含义**：
- $\|\cdot\|$ — 欧几里得距离 (向量长度)。
- $L_\text{tendon}$ — 腱总长度 (随软体变形而变)。

**公式解读**：把弯曲腱分解为多个直线段累加。

### 1.2 不可伸长约束 (精确模型)

$$L_\text{tendon}(t) = L_0 - \delta(t)$$

**变量含义**：
- $L_0$ — 静止时腱长度。
- $\delta(t)$ — 电机已拉入的腱长度 (随时间变化)。

**公式解读**：腱本身长度 + 电机拉入 = 总长度守恒。这是 **运动学约束**, 需要 LCP / Lagrange 乘子求解, 计算昂贵。

### 1.3 单一张力假设 (本论文简化)

放弃运动学约束, 假设腱内 **张力处处相等**:

$$\|\mathbf{T}_0\| = \|\mathbf{T}_1\| = \cdots = \|\mathbf{T}_N\| = f_T$$

**变量含义**：
- $\mathbf{T}_i \in \mathbb{R}^3$ — 第 $i$ 个 waypoint 处腱拉力 (向量)。
- $f_T \in \mathbb{R}_+$ — 标量张力 (单位 N), 由电机决定。

**公式解读**：忽略腱伸长, 但保留主要力学效果。这是 **静力学近似**, 比精确约束快得多 (10-50×)。

## 2. 腱对结构的作用力

### 2.1 第 $i$ 段腱的方向

```
   P_{i-1}             P_{i+1}
     ●─────┐    ┌─────●
           │    │
           ▼    ▼
              ●         ← P_i: 同时被两段腱拉
              │
            (合力)
```

第 $i$ 段腱 (从 $\mathbf{P}_i$ 指向 $\mathbf{P}_{i+1}$) 的单位方向向量:

$$\hat{\mathbf{t}}_i = \frac{\mathbf{P}_{i+1} - \mathbf{P}_i}{\|\mathbf{P}_{i+1} - \mathbf{P}_i\|}$$

**变量含义**：
- $\hat{\mathbf{t}}_i$ — 单位方向向量 ($\|\hat{\mathbf{t}}_i\| = 1$)。
- 分子: 位移向量。
- 分母: 距离 (标量)。

**公式解读**：归一化让向量长度为 1, 只保留方向信息。

腱拉力向量:
$$\mathbf{T}_i = f_T \cdot \hat{\mathbf{t}}_i$$

### 2.2 投影到表面切平面 (本论文 Eq. 1)

腱 waypoint 通常嵌在软体网格 **表面** $S_i$ 上, 该表面有外法线 $\mathbf{n}_{S_i}$。腱拉力分两个分量:
- **法向分量**: 把腱压入软体 (实际由结构反作用抵消)。
- **切向分量**: 真正驱动软体变形。

切向分量公式:
$$\boxed{\mathbf{T}_{\|S_i} = (\mathbf{I} - \mathbf{n}_{S_i}\mathbf{n}_{S_i}^\top)\,\mathbf{T}_i}$$

**变量含义**：
- $\mathbf{n}_{S_i} \in \mathbb{R}^3$ — 表面 $S_i$ 在 $\mathbf{P}_i$ 处的单位外法向, $\|\mathbf{n}_{S_i}\| = 1$。
- $\mathbf{n}_{S_i}\mathbf{n}_{S_i}^\top \in \mathbb{R}^{3 \times 3}$ — **投影矩阵** (秩 1), 把任何向量投影到 $\mathbf{n}_{S_i}$ 方向。
- $\mathbf{I} \in \mathbb{R}^{3 \times 3}$ — 单位矩阵。
- $\mathbf{I} - \mathbf{n}_{S_i}\mathbf{n}_{S_i}^\top$ — **切平面投影矩阵** (秩 2), 把向量投影到表面切平面。

**公式解读**：从总拉力 $\mathbf{T}_i$ 中减去其在法线方向的分量, 剩下的就是切向分量。这部分作为节点外力施加到 FEM 网格。

**几何直觉**: 想象桌面上拖一根绳, 绳与桌面有夹角, 真正使桌面变形 (滑动) 的是绳沿桌面方向的分量。

### 2.3 指尖特殊处理

最后一个 waypoint $i = N$ (指尖) 没有下一个 waypoint, 直接沿表面法线 **反向** 受力:

$$\mathbf{T}_N = -f_T\,\mathbf{n}_{S_N}$$

**公式解读**：腱在指尖锚定, 拉力把指尖向腱穿入方向 (即 $-\mathbf{n}$) 拉。负号让方向朝向软体内部。

## 3. 均匀压力腱布线 ⭐

### 3.1 物理目标

让整根手指 **均匀贴合物体表面**, 而不是 "**指尖卷起来**"。

**"卷起来"现象**：若 waypoint 等距分布 ($h_i = h$ 常数), 远端 waypoint 产生的弯矩按 $i^2$ 增长, 致远端弯曲过度。

### 3.2 Hirose 1978 推导

设：
- $L$ — 手指总长 (m)。
- $H$ — 指根处腱距铰链中线的高度 (m)。
- $l_i$ — 第 $i$ 个 waypoint 到指根的距离 (m)。
- $h_i$ — 第 $i$ 个 waypoint 到对应铰链中线的高度 (设计变量, m)。
- $M(l)$ — 腱在距离 $l$ 处对结构产生的弯矩 (N·m)。

**目标**: 让弯矩沿手指 **均匀分布**, 即:

$$\frac{d^2 M(l)}{dl^2} = c \quad (\text{常数, 表示均匀压力})$$

边界条件 (指尖自由端):
$$\left.\frac{dM}{dl}\right|_{l=L} = 0,\quad M(L) = 0$$

**变量含义**：第一个条件 = "**指尖剪力为零**" (无外力); 第二个 = "**指尖弯矩为零**"。

**两次积分**:

第一次:
$$\frac{dM}{dl} = c \cdot l + C_1$$

代入 $\frac{dM}{dl}|_{l=L} = 0$ → $C_1 = -cL$, 故 $\frac{dM}{dl} = c(l - L)$。

第二次:
$$M(l) = \frac{c}{2}(l - L)^2 + C_2$$

代入 $M(L) = 0$ → $C_2 = 0$, 故:

$$\boxed{M(l) = \frac{cL^2}{2}\left(1 - \frac{l}{L}\right)^2}$$

**公式解读**：弯矩从根部 ($l=0$, 最大值 $cL^2/2$) 二次衰减到指尖 ($l=L$, 0)。

### 3.3 推回 waypoint 高度

由 $M_i = T \cdot h_i = f_T \cdot h_i$ (弯矩 = 张力 × 力臂):
$$f_T \cdot h_i = \frac{cL^2}{2}\left(1 - \frac{l_i}{L}\right)^2$$

定义 $H = \frac{cL^2}{2 f_T}$ (指根处 $h_0 = H$):

$$\boxed{h_i = H\left(1 - \frac{l_i}{L}\right)^2}$$

**变量含义**：$H$ 是指根处的最大力臂, $l_i / L \in [0, 1]$ 是归一化距离。

**公式解读**：腱走线高度沿距离 **二次衰减**, 从根部 $H$ 到指尖 0。

### 3.4 公式直觉与几何含义

- 根部 ($l=0$): $h_0 = H$ (最大), 腱离铰链最远。
- 中段 ($l = L/2$): $h = H/4$ (急剧下降)。
- 指尖 ($l = L$): $h_N = 0$, 腱和铰链中线重合。

```
指根                                    指尖
═●═══════════════════════════════════●
 │ H  ╲                              │
 │     ╲                             │
 │      ╲___                         │
 │          ╲___                     │
 │              ╲___                 │
 │                  ╲╲___           │
 │                       ╲╲___      │
 │                            ╲╲══●←0
```

腱走线呈 **二次衰减曲线**——这就是软指内部的腱通道几何。

### 3.5 实验对比

| 走线 | 指头行为 |
|---|---|
| 等距 ($h_i = H$) | 指尖卷起来, 只有指尖触物 |
| 均匀压力 ($h_i = H(1-l_i/L)^2$) | 整根贴合物体 |

## 4. 腱驱动器选型

### 4.1 电机扭矩 → 腱张力

电机轴上卷筒半径 $r_d$, 电机扭矩 $\tau_m$:
$$f_T = \frac{\tau_m}{r_d}$$

**变量含义**：
- $\tau_m$ (N·m) — 电机输出扭矩。
- $r_d$ (m) — 卷筒半径。
- $f_T$ (N) — 腱张力。

**公式解读**：扭矩 = 力 × 力臂, 反推力臂上的拉力。

### 4.2 电机转角 → 腱拉入长度

$$\delta = r_d \cdot \theta_m$$

**变量含义**：
- $\theta_m$ (rad) — 电机转角。
- $\delta$ (m) — 腱被拉入电机的长度。

**公式解读**：弧长 = 半径 × 角度。

### 4.3 本论文具体参数

- 电机: Dynamixel XL330 (位置控制, 4096 units / rev)。
- 拉腱距离: 1000 units = 1/4 圈 (~$\pi/2$ rad)。
- 腱: 高强度 Dyneema 绳。

## 5. 腱驱动建模复杂度对比

| 模型 | 约束 | 代价 | 适用 |
|---|---|---|---|
| 完整 Lagrange (SOFA) | $\sum\|\mathbf{P}_{i+1}-\mathbf{P}_i\| = L_0$ + LCP | 慢 (秒级) | 学术精确 |
| 单一张力 (本论文) | 切向力施加 | 快 (ms 级) | 实时 / 大规模 |
| 解析弯曲 (Cosserat) | 杆元 + 内力方程 | 中 | 单段连续臂 |

本论文选 **单一张力** 因 80k 数据并行生成可行性。

## 6. 工程考虑

- **摩擦**: 腱与通道壁产生摩擦, 远端实际张力小于近端 (本论文忽略, 短指 + 光滑通道)。
- **弹性伸长**: 高强度腱仍有微小伸长 (~0.1%-1%), 长指可累积。
- **磨损 / 疲劳**: 腱反复弯折 $10^4-10^6$ 次后断裂。
- **路径死锁**: waypoint 几何不当时腱可能在转折处自锁。
