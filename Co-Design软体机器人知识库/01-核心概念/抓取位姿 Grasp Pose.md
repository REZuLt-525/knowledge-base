# 抓取位姿 Grasp Pose

> **一句话理解**：夹爪在抓取瞬间的 **位置 + 姿态** ($\mathbb{R}^6$)——决定了哪两根手指夹在物体的哪个部位、以什么角度夹。

`#核心概念`

---

## 1. 定义

抓取位姿 (Grasp Pose) 通常表示为：
$$p = [t_x, t_y, t_z, r_r, r_p, r_y] \in \mathbb{R}^6$$
(或用四元数表达的 $[t, q] \in \mathbb{R}^{3+4}$)

加上 **开合度** (夹爪张角 $s$) 或 **力度** 就构成完整的抓取指令。

---

## 2. 抓取位姿的生成方法

| 思路 | 代表 |
|---|---|
| **解析法** (Form/Force Closure) | 传统力学约束求解 |
| **数据驱动**：监督学习 | [[../03-参考文献/Ref-46-Fang-2023-AnyGrasp|AnyGrasp]] |
| **强化学习** | DexNet, Meta-World |
| **生成模型** | GraspGen, diffusion |
| **采样 + 评估** | 本论文采用 AnyGrasp 初筛 + 代理打分 |

---

## 3. 本论文的位姿工作流

```
  RGB-D ➜ Point Cloud ➜ AnyGrasp ➜ 候选位姿 {p_i}
                            │
                            ▼
             位姿增广 (SDF 优化, 防碰撞)
                            │
                            ▼
         神经代理 f_θ 评估每个 (p_i, k) 得 loss
                            │
                            ▼
                选择 Top-B = 5 做刚度梯度
```

### 3.1 位姿增广 (SDF 优化)

- AnyGrasp 默认夹爪长度较短，本论文夹爪更长导致原位姿 **碰地或穿透物体**。
- 附加一个"刚性代理" (rigid gripper，由软夹爪网格构造)，以 6D 自由关节 + 2 个 prismatic (开合) 共 $\mathbb{R}^8$ 参数化。
- 对每个候选位姿加噪 $t + \mathcal{N}(\mu_t, \sigma_t)$、$r + \mathcal{N}(\mu_r, \sigma_r)$，再用 **SDF** (见 [[../00-总览/专业术语词典|SDF]]) 做无碰撞优化：
$$\arg\min_{t_y, s_1, s_2} \; w_d \sum_i \max(d_i, 0) + w_p \sum_i \max(-d_i, 0)$$
- 小 $w_d$ 让夹爪贴近物体/地面，大 $w_p$ 避免穿透。

### 3.2 位姿评估 (代理打分)

在优化和部署时，使用神经代理 $f_\theta(p, k, \text{obj})$ 返回预测末态，用 Loss 从小到大排序，选最优 $p^*$。

---

## 4. 位姿与设计耦合 (为何要联合优化?)

一个有趣的现象：**最佳刚度分布依赖于位姿**。举例：
- 若从正上方抓圆柱，软指尖更好；
- 若侧向抓细长物体，硬中段更好。

因此位姿 (控制) 与刚度 (硬件) **必须协同**。这是 co-design 的具体体现。算法 1 的外层在 Top-B 位姿内排序、内层对刚度梯度下降，达成联合优化。

---

## 5. 真机部署时的位姿选择

- 合并两相机点云→基座标系→裁剪目标物体。
- 送入已训练的神经代理。
- 在当前 (固定) 夹爪设计下选最优位姿，发送到 Franka 机械臂执行。
- 失败时 (不可达或碰撞) 丢弃该候选，选下一个。
