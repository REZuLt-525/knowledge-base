# 代理模型 Surrogate Model

> **一句话理解**：用一个 **训练速度一般、推理飞快** 的近似模型替代 **又贵又慢** 的真实模型，加速搜索和优化。

`#核心概念`

---

## 1. 什么是代理模型？

**Surrogate / Proxy / Meta-model** 是工程优化的经典概念：
- 真实模型 $f^\star$ 昂贵 (仿真、实验)。
- 训练代理 $\hat{f}_\theta$ 近似 $f^\star$。
- 之后所有 `argmin`、`argmax`、采样都用 $\hat{f}_\theta$。

```
数据生成 (慢, 一次)    → 训练代理 → 优化用代理 (快, 百万次)
```

---

## 2. 常见代理模型

| 模型 | 优点 | 局限 |
|---|---|---|
| **高斯过程 (GP)** | 有不确定度、样本高效 | 数据 > 1 万时慢 |
| **神经网络 (NN)** | 通用、可微 (本论文用) | 不确定度不显式 |
| **多项式响应面** | 简单、可解释 | 低维才好 |
| **GNN/MeshNet** | 处理结构/图数据 | 训练成本高 |
| **扩散模型** | 生成式 | 昂贵 |

本论文使用 **PointNet + MLP** 的前向神经代理，结构简洁、推理快。

## 3. 代理模型在 Co-Design 的角色

### 3.1 加速评估
Co-design 每次改设计都要评估任务表现。代理把评估从"秒级 FEM"降到"毫秒级推理"，整体节约 3 个数量级 (论文 Fig 4d)。

### 3.2 平滑梯度
神经网络天生平滑、可微，修补原始物理梯度的锐利/抖动/断裂问题。这是 **本论文选择代理路线的关键理由**。

### 3.3 贝叶斯优化的基石
BO 本质上就是"代理 + 采集函数" 的循环，见 [[../02-方法分类/采样优化方法]]，[[../03-参考文献/Ref-22-Calandra-2016-BO]]、[[../03-参考文献/Ref-23-Snoek-2012-PracticalBO]]。

### 3.4 硬件代理 (Hardware Proxy)
He 等提出 **MORPH** ([[../03-参考文献/Ref-07-He-2024-MORPH]]) 用可微硬件代理替代难微分的真实机械动力学，巧妙嵌入 RL 训练循环。

## 4. 代理模型的注意事项

- **数据分布**：训练集要覆盖优化过程会走到的区域 (OOD 是大坑)。
- **不确定度感知**：贝叶斯 / 集成法可以避免在代理"无信心"的地方盲目优化。
- **在线更新**：遇到差距大时可能需要主动查询真模型并微调代理。
- **验证**：优化结束后务必用真模型重新评估 (本论文在 FEM 中做了大量验证和真机实验)。
