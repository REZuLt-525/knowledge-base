# 神经物理模拟器 Neural Physics

> **一句话理解**：让神经网络学会"玩物理"，输入系统状态和参数，输出下一时刻/最终状态——既快又可导。

`#核心概念`

---

## 1. 为什么需要神经物理？

传统物理模拟 (FEM、SPH、MPM 等) 准确，但 **每次求解都很慢**，尤其是软体+接触+变刚度这类非线性问题。

在 Co-Design 中，我们要对设计参数做 **数千次到百万次** 评估，纯物理模拟扛不住。

**两条出路**：
1. **可微分模拟**：仍然是物理模拟，但支持反向传播。见 [[可微分模拟 Differentiable Simulation]]。
2. **神经物理代理**：用数据训一个网络代替模拟器。见本页。

---

## 2. 三种主流神经物理

### 2.1 "黑盒"前向网络 ⭐ 本论文方案

- 输入：状态 $s_t$ (或系统参数)
- 输出：状态 $s_{t+1}$ 或末态 (例如最终物体位姿、受力)
- 结构：MLP / CNN / PointNet / Transformer 等。

**优点**：推理快、梯度天然平滑。
**缺点**：泛化性受训练分布限制；物理约束需要靠数据"学到"而非强制。

> 本论文就是这一类：PointNet 编码物体点云 + 22 维刚度 → MLP → 输出末态 6D 力 & 3D 位移 & 接地指示。

### 2.2 图神经网络 (GNN) 模拟器

- 节点 = 网格顶点 / 粒子
- 边 = 相邻关系
- 通过消息传递模拟局部相互作用

代表：
- **MeshGraphNets** ([[../03-参考文献/Ref-28-Pfaff-2021-MeshGraphNets]])：网格模拟布料、流体。
- **Allen'22** ([[../03-参考文献/Ref-20-Allen-2022-InverseDesignGNS]]) 和 GD-M ([[../03-参考文献/Ref-30-Allen-2022-GDM]])：用图网络做 inverse design。
- **CFD-GCN** ([[../03-参考文献/Ref-29-deAvilaBelbute-2020-GraphPDE]])：组合可微 PDE 解法器与 GNN。

### 2.3 物理信息 / 硬约束网络

- PINN (Physics-Informed Neural Networks)
- 强制网络满足 PDE 残差、守恒律

这类研究较多在流体、电磁学领域。本知识库未重点覆盖。

## 3. 关键设计问题

### 3.1 输入表示如何选？

| 表示 | 优点 | 缺点 |
|---|---|---|
| 全量网格 | 精度高 | 参数大、位置依赖 |
| 点云 (PointNet) | 置换不变、轻量 (本论文) | 丢失拓扑 |
| 图结构 (GNN) | 表达局部交互 | 训练/推理成本较高 |
| 体素 (3D CNN) | 规则网格 | 分辨率限制 |

### 3.2 预测目标：逐步 vs 末态

- **逐步预测** (rollout)：易累积误差，但能展示动态过程。
- **末态预测** (本论文)：直接监督最终结果，训练稳定，但丢失中间信息。

### 3.3 如何利用梯度？

优化时要 $\partial\text{Loss}/\partial k$。神经网络天生支持自动微分，这是代理模型 (surrogate) 比原始模拟更好的地方——原始模拟的梯度可能因接触、塑性、锐利几何而断裂。

## 4. 本论文神经物理的细节

```
输入 Input                              编码器           主干
 - 物体局部点云 (N × 3)  ─┐
 - 夹爪边界框内裁剪       │→ PointNet (3 层) → 128-d
 - 质心 (3) + 密度 (1)  ─┤→ concat
 - 刚度 k ∈ ℝ²²         ─┘
                          ↓
                  5-layer MLP (ReLU)
                          ↓
                  输出 Output
                 ─ 末态合力 f ∈ ℝ⁶
                 ─ 末态位移 Δq ∈ ℝ³
                 ─ 是否碰地 c_g ∈ {0,1}
```

- **数据量**：约 80,000 样本 (45 YCB 物体 × 50 位姿 × 50 刚度，过滤无效后)
- **损失**：L1 loss。
- **效率**：训练 1 小时 (1 × 3090 GPU)；比原 FEM 模拟快约 1000×。

### 平滑性带来的好处 (论文 Fig 4)

- 可微分 FEM 的梯度大而噪声高。
- 神经代理的梯度小而平滑。
- 梯度下降更稳定，不易陷局部极小，且计算快 3 个数量级。

---

## 5. 局限性

作者在 §6 坦言：
- 神经代理只在训练分布附近有效，OOD (out-of-distribution) 物体精度下降。
- 依赖 water-tight 高质量网格，数据集质量是瓶颈。
- 代理无法处理大几何变化——这是为什么本论文不优化几何。
