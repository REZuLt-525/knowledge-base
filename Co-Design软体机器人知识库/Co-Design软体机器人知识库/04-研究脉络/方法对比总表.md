## 🎯 按"设计自由度" 排序

```
生成式  ≈  RoboGrammar  ≈  拓扑优化  > RL协同进化 > 可微分物理  > 本论文 > BO/规划式
         (高: 几何 / 拓扑)                    (中: 参数 / 刚度)       (低: 超参)
```

## 🎯 按"样本效率" 排序

```
BO  >  代理+采样 (本论文) >  可微分物理  ≈  拓扑优化  >  RL协同进化  >  进化/GA
```

## 🎯 按"Sim-to-Real 友好度" 排序

```
规划式设计  >  BO (小变量 → 易辨识)  >  本论文 (刚度标定简单)  >  可微分物理  >  RL协同进化  >  生成式
```

## 🧭 决策指南：该选哪条路线？

- 🎯 **目标：探索新结构形态**
  - 生成式设计 / 图语法 / GA

- 🎯 **目标：在已有形态上调最优参数**
  - BO / CMA-ES / 可微优化

- 🎯 **目标：软体机器人，有大量数据但梯度难算**
  - **本论文路线**：神经代理 + 采样

- 🎯 **目标：复杂控制 + 硬件优化**
  - MORPH / Hardware-as-Policy

- 🎯 **目标：结构离散、组合性强**
  - RoboGrammar / 模块化 GA / 规划式

- 🎯 **目标：真机快速落地**
  - 本论文 / Schaff'23 / MORPH (需要 DR)
