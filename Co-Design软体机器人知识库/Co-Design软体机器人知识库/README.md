## 🎓 如何使用这个知识库

1. **作为 Obsidian Vault 打开**：在 Obsidian 中选择 `打开保管库` → 选择本文件夹即可。
2. **查看图谱**：`Ctrl/Cmd + G` 打开 Graph View，按主题色区分节点。
3. **按学习路径**：新手建议先读 [[00-总览/新手学习路径]]，有经验的读者可直接跳到感兴趣的文献节点。
4. **双链导航**：任何 `[[链接]]` 都可点击跳转，背链 (Backlinks) 面板显示哪些文档引用了当前文档。
