# [26] Ha, Agrawal & Song 2021 · Fit2Form

> **原文**: H. Ha, S. Agrawal, S. Song. *Fit2Form: 3D generative model for robot gripper form design.* **CoRL 2021**, pp. 176-187.
> **译名**: 《Fit2Form: 面向机器人夹爪形态设计的 3D 生成模型》 — 机器人学习大会 (CoRL), 2021.

`#文献-方法` `#生成式设计` `#里程碑`

---

## 1 · 研究问题

夹爪几何对抓取性能影响巨大, 但 **几何空间自由度极高** (体素 / 网格自由变化, $\sim 10^4$ 维)。Columbia Shuran Song 团队的目标:

> 训练一个 **3D 生成模型** $G_\theta$, 输入目标物体形状, **直接输出最适合该物体的夹爪几何** — 一次前向、零迭代得设计。

应用: 定制化夹爪 — 装配线某零件、医院某药瓶等专用场景。

---

## 2 · 形式化

### 2.1 表示选择: 体素 (voxel)

物体和夹爪都用 $32^3$ 或 $64^3$ 二值体素网格表示:
$$O \in \{0, 1\}^{32 \times 32 \times 32},\;\; G \in \{0, 1\}^{32 \times 32 \times 32}$$

为何选体素而非 mesh? — 神经网络 (3D CNN) 直接处理, 无需图结构。

### 2.2 生成目标

学习条件分布:
$$p_\theta(G | O)$$

理想情况下, 给定物体 $O$, 生成器输出能稳抓 $O$ 的夹爪 $G$。

### 2.3 训练数据

```
1) 在物体库 (ShapeNet 子集) 中采样物体 O
2) 在仿真中:
    - 采样夹爪体素 G (随机扰动)
    - 评估抓取分数 s(O, G) ∈ [0, 1]
3) 数据集: D = {(O_i, G_i, s_i)}
```

---

## 3 · 模型架构

### 3.1 主干: 条件自编码器 + GAN

```
输入 物体 O (voxel)
         │
         ▼ 3D CNN 编码器 E_obj
潜空间 z_obj ∈ R^{128}
         │
         ▼ 3D 反卷积解码器 G_θ
生成夹爪 Ĝ (voxel)

判别器 D:
   输入 (O, G), 输出真假概率
```

### 3.2 训练损失

$$L_\text{total} = L_\text{recon} + \alpha L_\text{adv} + \beta L_\text{task}$$

#### 重建损失
$$L_\text{recon} = \|G_\theta(z_\text{obj}) - G_\text{ref}\|^2$$
$G_\text{ref}$ 是已知的"好夹爪"模板。

#### 对抗损失 (GAN)
$$L_\text{adv} = \mathbb{E}_O[\log D(O, G_\text{real})] + \mathbb{E}_O[\log(1 - D(O, G_\theta))]$$

#### 任务损失 (核心创新)
$$L_\text{task} = -\mathbb{E}_O[s(O, G_\theta)]$$
$s$ 是仿真抓取成功率, 通过可微仿真或 RL gradient 反传。

### 3.3 训练流程

```
─── Fit2Form Training ───────────────────────
重复 epoch:
    # 数据采样
    batch (O_i, G_ref_i, s_i) from D
    
    # 编码 + 生成
    z_obj_i = E_obj(O_i)
    Ĝ_i = G_θ(z_obj_i)
    
    # 判别器
    D_loss = adversarial_loss(D, O_i, G_ref_i, Ĝ_i)
    update D
    
    # 生成器 (含任务损失)
    G_loss = recon(Ĝ_i, G_ref_i) + α·D(O_i, Ĝ_i) - β·sim_grasp_score(O_i, Ĝ_i)
    update G_θ via backprop
```

## 4 · 制造与验证

### 4.1 体素 → mesh
- 用 Marching Cubes 把体素 $G$ 转为 mesh。
- 平滑处理 (Laplacian smoothing)。
- 输出 STL → 3D 打印。

### 4.2 真机抓取测试
- 把生成夹爪装到机械臂。
- 让其抓对应物体。
- 测试 100 类物体。

---

## 5 · 实验

### 5.1 量化结果

| 方法 | 抓取成功率 | 设计时间 |
|---|---|---|
| 通用平行夹钳 | 65% | 0 |
| 经典 form closure ([[Ref-17-Kodnongbua-2023-PassiveGrippers]]) | 85% | ~分钟 |
| **Fit2Form** | **80-85%** | **~秒 (一次前向)** |

Fit2Form 抓取性能与经典方法相当, 但 **生成时间快 1000 倍**。

### 5.2 多样性
- 不同物体生成的夹爪形状差异巨大。
- 同一物体多次采样可得多种合理夹爪 (CVAE / GAN 多样性)。

### 5.3 失败模式
- 复杂凹腔物体: 生成夹爪可能无法插入。
- 极小物体 (< 5 mm): 体素分辨率不足。

---

## 6 · 关键贡献

1. **生成式夹爪设计**: 首次用生成模型直接产出 3D 夹爪几何。
2. **任务损失嵌入**: 让生成器知道"功能"而非仅"外观"。
3. **快速部署**: 推理速度 vs 经典优化方法的 1000× 优势。

---

## 7 · 局限

1. **体素分辨率受限**: $32^3$ 不能表达细节, $64^3$ 内存爆。
2. **可制造性后处理**: 需 mesh 重建, 不直接打印。
3. **任务损失依赖可微仿真**: 接触场景仍受限。
4. **不联合优化控制**: 仅生成几何, 控制策略另算。

## 9 · 与本论文 (Yi'25) 的关系

哲学差异:
- Fit2Form: 一次性生成几何 (生成式)。
- 本论文: 迭代优化刚度 (优化式)。

互补 use case:
- Fit2Form 适合 **从 0 探索新形态**。
- 本论文适合 **在已知形态上精调局部参数**。

未来融合: Fit2Form 给几何骨架 → 本论文优化局部刚度。
