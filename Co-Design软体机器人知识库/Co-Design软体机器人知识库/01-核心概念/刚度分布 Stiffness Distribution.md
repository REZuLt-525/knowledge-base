# 刚度分布 Stiffness Distribution

> **一句话理解**：把"夹爪整体硬度" 拆成 **沿空间分布的局部刚度场** $E(\mathbf{x}) \in \mathbb{R}_+^M$，其中每段 / 每元素独立可调；通过 co-design 找到最优分布 $E^*(\mathbf{x})$，使得指定任务 (抓取成功率) 最大化。

`#核心概念`

---

## 1. 形式化定义

### 1.1 离散刚度场

把软体结构离散为 $M$ 个 block (本论文 $M = 22$), 每个 block 独立模量:

$$\mathbf{k} = (\log E_1, \log E_2, ..., \log E_M)^\top \in \mathbb{R}^M$$

**变量含义**：
- $E_i$ — 第 $i$ 个 block 的等效杨氏模量 (Pa)。
- $\log E_i$ — 取对数变换 (因为 $E$ 跨多个数量级)。
- $\mathbf{k}$ — **22 维设计向量**, co-design 优化变量。

**为何用 $\log$**? $E \in [0.7 \text{ MPa}, 24 \text{ MPa}]$ 跨 1.5 个数量级。在原始 $E$ 域优化, 大值会主导梯度; **log 域线性更适合优化**, $\log E \in [13.5, 17.0]$ 范围更均匀。

### 1.2 优化问题

$$\mathbf{k}^* = \arg\min_{\mathbf{k} \in \mathcal{K}} \;\; \mathbb{E}_{(o, p) \sim \mathcal{D}} L(\mathbf{k}, p, o)$$

**变量含义**：
- $\mathcal{K} = [13.5, 17.0]^{22}$ — **可制造刚度范围** (本论文)。
- $\mathcal{D}$ — 物体-位姿分布 (45 件 YCB × 50 候选位姿)。
- $o$ — 物体。
- $p$ — 抓取位姿。
- $L$ — 抓取损失 (合力、位移、是否触地)。

**公式解读**：在所有可制造刚度向量中, 找到使期望抓取损失最小的那个。

### 1.3 本论文 Loss 具体形式 (Eq. 4)

$$L_\text{opt}(p, \mathbf{k}) = w_1 \sum_{o \in O}(\|f\|_2 + \|\Delta q\|_2) + w_2 \sum_{o \in O}(|\min(f_y, 0)| + |\min(\Delta q_y, 0)| + c_g)$$

**变量含义** (再列一次, 重要):
- $f \in \mathbb{R}^6$ — 末态合力 (3 力 + 3 力矩, 单位 N 和 N·m)。
- $\|f\|_2 = \sqrt{f_1^2 + ... + f_6^2}$ — L2 范数 (合力大小)。
- $\Delta q \in \mathbb{R}^3$ — 末态物体位移。
- $f_y, \Delta q_y$ — y 方向 (向下) 分量。
- $\min(\cdot, 0)$ — 取负部分; 例 $\min(-3, 0) = -3, \min(2, 0) = 0$。
- $|\min(\cdot, 0)|$ — 负部分的绝对值; 表示 "**只惩罚下降, 不惩罚上升**"。
- $c_g \in \{0, 1\}$ — 是否触地 (1 = 触地, 失败信号)。
- $w_1, w_2$ — 权重系数 (本论文 $w_1 = 1, w_2 = 10$)。

**公式解读**：
- **第 1 项**: $w_1$ 加权基础抓取稳定 (合力小 + 位移小)。
- **第 2 项**: $w_2$ 加权防掉落 — 重点惩罚 -y 方向受力 (物体被拉下)、-y 位移 (物体下移)、触地 (掉了)。

## 2. 刚度分布的物理意义

### 2.1 单 block 行为

每段 block 在腱拉力作用下产生弯曲。FEM Neo-Hookean 本构下, 受力下产生的位移 $\delta$ 近似:

$$\delta \propto \frac{F \cdot l^3}{E \cdot I}$$

**变量含义**：
- $F$ — 局部受力 (N)。
- $l$ — block 长度 (m)。
- $E$ — block 杨氏模量 (Pa)。
- $I$ — 截面惯性矩 (m⁴)。
- $\delta$ — block 末端弯曲位移 (m)。

**公式解读**：欧拉-伯努利梁的"末端挠度"近似。
- $E$ 越大 → $\delta$ 越小 → block 刚 (不易变形)。
- $E$ 越小 → $\delta$ 越大 → block 软 (易顺应物体)。
- $l^3$ 关系让长 block 更易变形。

### 2.2 全局形态: 贴合 vs 承载

| 全局刚度 | 行为 | 适合场景 |
|---|---|---|
| 全软 ($E \approx 0.7$ MPa) | 极易变形 → 好贴合 | 轻物 |
| 全硬 ($E \approx 24$ MPa) | 几乎不变形 → 强承载 | 形状规则 + 重 |
| **优化分布** | 局部软 + 局部硬 | 多物体通用 |

co-design 的核心价值: 让算法找到 "**哪个 block 该硬, 哪个该软**" 的非平凡组合。

## 3. 本论文优化结果分析

### 3.1 最优刚度向量 (论文 Table 4)

```
指 1 (从根到指尖):
  [16.05, (15.16), 14.62, (14.89), 15.31, (14.62), 15.85, (14.65), 15.23, (15.34), 15.22]
   seg   flex     seg    flex     seg    flex     seg    flex     seg    flex     seg

指 2:
  [15.54, (14.53), 14.27, (14.81), 15.00, (15.97), 14.54, (15.14), 14.95, (15.31), 15.47]

(括号内为 flexure 块, 否则为 segment 块)
log E 范围 [14.27, 16.05] (即 E ≈ 1.6 - 9.4 MPa)
```

### 3.2 模式提取

**模式 A · 不对称**: 两指刚度分布 **不一样** — 一指偏软适配, 一指偏硬承力。

**模式 B · 硬指尖**: 靠近指尖的 segment 偏硬 (~15.5)。直觉相反 — 人类直觉认为指尖应软贴合。

**模式 C · 软中段**: 中部 flexure 较软 (~14.5), 提供主要弯曲。

**模式 D · 硬基座**: 根部 segment 最硬 (~16), 提供整体支撑。

### 3.3 反直觉的"指尖硬"

为什么指尖反而硬?
- 当物体被夹住后, **最易滑脱处** 是指尖 (杠杆最长)。
- 硬指尖提供 **最后的承力点**。
- 类比: 灵长类的 **指甲** 也是硬的。

co-design 算法 **从数据自动发现** 这种工程直觉之外的设计。

## 5. 刚度分布的工程实现

### 5.1 多材料路线 (例如 PolyJet)

不同 block 用不同硬度树脂打印, 分辨率高但设备贵。
代表: [[../03-参考文献/Ref-35-Hubbard-2021-3DPrintedFluidic]]。

### 5.2 单材料 + 结构 (本论文路线)

同一种 TPU, 通过 **wall loops + infill** 改变结构等效模量:

$$E_\text{eff} = E_\text{base} \cdot \alpha(\text{结构参数})$$

**变量含义**：
- $E_\text{base}$ — 实心 TPU 95A 模量 (~30-50 MPa)。
- $\alpha \in [\sim 0.05, 1]$ — 结构衰减系数。
- $E_\text{eff}$ — 等效模量。

**公式解读**：实心比例越低, $\alpha$ 越小, 等效模量越软。覆盖一个数量级以上, 桌面 FDM 打印机即可完成。

### 5.3 结构-模量映射 (论文 §4.2 标定)

对每种打印参数组合做实测:
- Flexure 块: 三点弯曲, $E = PL^3 / (48 I \delta)$。
- Segment 块: 压痕, $E = (1-\nu^2)P / (2 a \delta)$。

(详见 [[柔性铰链 Flexure Joint]])

得到查找表 → 仿真 $\log E$ 线性映射到具体打印设置。

## 6. 比较: 刚度分布 vs 拓扑优化

| 维度 | 刚度分布 (本论文) | 拓扑优化 ([[../03-参考文献/Ref-12-Chen-2018-拓扑优化软夹爪]]) |
|---|---|---|
| 设计变量 | 22 维 (block 模量) | $10^3-10^5$ 维 (元素密度 $\rho_e$) |
| 几何 | 固定 | 动态 (材料有/无) |
| 求解 | NN 代理 + 梯度 | SIMP + 伴随法 |
| 制造性 | 直接 (打印参数) | 后处理 (阈值化 + 平滑) |
| 接触场景 | ✅ (神经代理) | ❌ (静态线性问题) |

**本论文是 "结构级拓扑优化的子问题"** — 限定几何, 仅优化材料属性。
