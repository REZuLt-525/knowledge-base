# 生成式设计

> **一句话理解**：训练一个生成模型 (GAN / VAE / Diffusion) **直接输出** 满足任务的机器人形态，而不是通过迭代优化。

---

## 1. 核心思想

与梯度/采样不同，生成式方法学习 **设计分布 $p(x_\text{design} \mid \text{task})$**，一次前向就得出候选设计。

```
 任务条件 (物体、物理属性)
       │
       ▼
 [生成模型]
       │
       ▼
 候选机器人形态 (几何/参数)
```

---

## 2. 代表工作

### 2.1 Fit2Form — Ha et al. 2021
[[../03-参考文献/Ref-26-Ha-2021-Fit2Form]]
- 3D 生成模型输出夹爪形态，使其匹配特定物体。
- 用自动编码器 + GAN 训出可生成的 voxel 表示。

### 2.2 Dynamics-Guided Diffusion — Xu et al. 2024
[[../03-参考文献/Ref-27-Xu-2024-DynamicsDiffusion]]
- 用 **扩散模型** 生成机器人操作器形态。
- 条件为动力学行为 (例如"捏起重物"的期望动态)。
- 扩散模型平滑性带来多样化设计。

### 2.3 其他
- **Neural 设计探索** (NASA, 汽车、航空)：主要面向工程结构。
- **RoboGrammar** ([[../03-参考文献/Ref-08-Zhao-2020-RoboGrammar]]) 虽非生成模型，但图语法也属于"规则生成"一类。

---

## 3. 优缺点

| 优点 | 缺点 |
|---|---|
| 一次前向产生设计 | 仍需物理仿真验证 |
| 易嵌入条件 (任务向量) | 需大量训练数据 |
| 可生成多样化方案 | 可能产生不可制造的形状 |
| 易与 LLM / 其它模态组合 | 可控性不如显式优化 |

---

## 4. 与本文的关系

- 本文未使用生成式设计：刚度是连续向量，可微优化效率更高。
- 但作者在 **展望** (Conclusion) 提到未来可整合 **large action models** 扩展到更复杂的多阶段操作。
- 生成式方法和 co-design 的自然结合是：**生成先验 + 代理验证 + 梯度微调**。
