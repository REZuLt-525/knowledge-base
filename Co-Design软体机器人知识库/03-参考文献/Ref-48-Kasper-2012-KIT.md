# [48] Kasper, Xue & Dillmann 2012 · KIT 物体模型数据库

> **原文**: A. Kasper, Z. Xue, R. Dillmann. *The KIT object models database: An object model database for object recognition, localization and manipulation in service robotics.* **IJRR**, 31(8):927-934, 2012.
> **译名**: 《KIT 物体模型数据库：用于服务机器人物体识别、定位与操作的物体模型数据库》 — *国际机器人研究学报 (IJRR)*, 2012.

`#文献-数据集`

---

## 1 · 研究问题

德国 Karlsruhe Institute of Technology (KIT) 的 Rüdiger Dillmann 教授团队 2000 年代起建设 **家庭服务机器人 ARMAR** 系列 — 机器人要在厨房、客厅识别 + 操作物体。当时缺少高质量、欧式风格的家居物体 3D 数据集。Kasper 等的目标:

> 建立一个 **服务机器人专用** 的物体模型数据库, 提供 (a) 高精度 3D 网格, (b) 多视角真实图像, (c) 物理参数, 并制定 **标准化采集与标注流程** 便于跨实验室共享。

---

## 2 · 数据集组成

### 2.1 物理物体

110+ 件物体, 分类:
- **食品包装**: 麦片盒、巧克力、罐头。
- **饮料瓶**: 酒瓶、水瓶、调料瓶。
- **餐具**: 盘、碗、刀、叉、汤勺。
- **办公用品**: 订书机、剪刀、胶水。
- **儿童玩具**: 积木、木偶、毛绒玩具。

特色: **欧式家居风格** (柏林超市常见), 与美式 YCB ([[Ref-44-Calli-2015-YCB]]) 互补。

### 2.2 数字模型

每件物体提供:
- **高精度 mesh** (扫描自实物, 分辨率 0.5 mm)。
- **简化版 mesh** (~$10^4$ 三角形, 实时渲染)。
- **PBR 纹理图**。
- **24-48 视角 RGB-D 图**。
- **物理参数** XML 元数据。

### 2.3 物理参数标注

| 参数 | 测量方法 |
|---|---|
| 质量 (kg) | 数字天平 |
| 包围盒尺寸 (mm) | 卡尺 |
| 重心位置 (mm) | 悬挂法 |
| 表面摩擦系数 | 倾斜板法 |
| 类别标签 | 人工标注 |

## 3 · 三维扫描工艺

### 3.1 设备
- **激光扫描仪** (Konica Minolta Range7): 0.1 mm 分辨率。
- **结构光扫描仪**: 处理光滑表面 (传统激光易反射)。
- **多视角 RGB 相机**: 高分辨率纹理。

### 3.2 流程

```
─── 扫描流程 ───────────────────────────────
1) 物体放置于自动转盘, 24 个角度
2) 每角度 5-10 秒扫描深度 + RGB
3) ICP 多视图配准 → 完整 mesh
4) Poisson 重建 (填充孔洞)
5) 纹理映射 (高分辨率 RGB → mesh)
6) 简化 (Quadric Edge Collapse) → 实时版
7) 物理参数测量 + 元数据生成
8) 入库 (ROS / OpenCV 兼容格式)
```

总耗时 ~ 4-8 小时 / 物体。

---

## 4 · 标准化协议 (核心贡献)

### 4.1 7 步采集协议

KIT 提出"标准化 7 步":
1. 物体准备 (清洁、固定姿态)。
2. 扫描设置 (转盘、光照)。
3. 多视角扫描。
4. 网格重建 (ICP + Poisson)。
5. 纹理处理。
6. 物理参数测量。
7. 元数据 + 入库。

让其他团队可扩充数据库, 保证一致性。

### 4.2 数据格式 (ROS / Gazebo 兼容)

```
object_name/
├── meshes/
│   ├── high_res.obj
│   ├── low_res.obj
│   └── collision.stl
├── textures/
│   ├── albedo.png
│   ├── normal.png
│   └── metallic.png
├── views/
│   └── rgb_*_depth_*.png
└── meta.xml  (mass, dimensions, friction)
```

## 5 · 关键贡献

1. **欧式风格补充**: 与 YCB 形成互补。
2. **标准化协议**: 让数据集可扩展。
3. **PBR 纹理**: 适合现代渲染管线 (RT、ray tracing)。
4. **物理参数完备**: 支持 sim2real。
5. **ARMAR 应用基础**: KIT 服务机器人系列依赖此库。

---

## 6 · 局限

1. **物体规模较小** (110 件) vs YCB (77 件) — 单独使用覆盖不够。
2. **风格偏欧式**: 不含亚洲 / 美式特色物体。
3. **数据采集慢**: 4-8 hr/物体, 难大规模扩充。

---

## 7 · 历史影响

- KIT 数据集激发后续多个家居物体集 (BigBIRD, ShapeNet 子集)。
- ARMAR 机器人系列依赖 KIT 作为基础库。
- 与 YCB 一道成为抓取研究 sim-to-real 重要参考。

---

## 8 · 与本论文 (Yi'25) 的关系

本论文 §4.1 用 KIT 物体作为 **out-of-domain (OOD) 测试集**:
- In-domain: 45 件 YCB (训神经代理)。
- Out-of-domain: 28 件 (KIT + EGAD + 部分 YCB)。

KIT 物体形状与 YCB 风格不同 → 真实泛化测试。OOD 性能略低于 in-domain (82% vs 92%) 但仍合理 → 证明 co-design 设计不只对 YCB 形状特化。
