## 1 · 研究问题

机器人 co-design 中, **动力学 (尤其接触)** 是不可微梯度的最大障碍: 硬接触 $F_n = k_n \max(0, -d)$ 在 $d=0$ 处导数跳变; 变形/塑性进一步引入数值不稳定。MIT CSAIL Wojciech Matusik、Pulkit Agrawal 团队的目标:

> 构建一个 **端到端可微分** 的机器人设计框架 *DiffHand*, 让 (硬件参数, 控制轨迹) 同时通过梯度下降优化, 且能稳定处理 **多刚体 + 软指 + 接触 + 大变形**。

## 2 · 系统形式化

### 2.1 设计与控制变量

$$\boldsymbol{\theta} \in \mathbb{R}^{d_h},\quad \mathbf{u}_{0:T-1}$$

**变量含义**：
- $\boldsymbol{\theta}$ — **硬件参数向量** ($d_h \sim 50$): 手指段长 $L_i$, 电机安装位置 $\mathbf{r}_m$, 关节摩擦 $\mu_j$ 等。
- $\mathbf{u}_{0:T-1} = (\mathbf{u}_0, ..., \mathbf{u}_{T-1})$ — **控制序列**: 每步关节扭矩或腱拉力。
- $T$ — 总时间步数。

### 2.2 平滑接触模型 (核心创新)

替换硬接触为 softplus:

$$F_n^\text{smooth}(d) = k_n \cdot \log\big(1 + e^{-d/\epsilon}\big)$$

**变量含义**：
- $F_n^\text{smooth}$ (N) — 平滑后的接触法向力。
- $d$ (m) — **间隙距离**: 物体表面间距离, 负值 = 穿透。
- $k_n$ (N/m) — 接触刚度系数 (典型 $10^6$)。
- $\epsilon$ (m) — **平滑系数** ($10^{-4}$ 到 $10^{-2}$), 控制过渡区宽度。

**性质**：
- $\epsilon \to 0$: 回到硬接触 $F_n = k_n \max(0, -d)$。
- 训练初期 $\epsilon$ 大 (~$10^{-2}$ m), 逐渐 anneal 到 ~$10^{-4}$ m。
- **处处可导 + 数值稳定**。

**导数**:
$$\frac{\partial F_n^\text{smooth}}{\partial d} = -\frac{k_n}{1 + e^{d/\epsilon}}$$

**变量含义**：分母是 sigmoid 形式。

**公式解读**：导数处处定义且光滑:
- $d \ll -\epsilon$ (深穿透): $\partial F_n / \partial d \to -k_n$ (硬接触梯度)。
- $d \gg \epsilon$ (远离接触): $\partial F_n / \partial d \to 0$ (无接触)。
- $d \approx 0$: 平滑过渡。

### 2.3 关节空间动力学

机械手的标准动力学方程:

$$\mathbf{M}(\mathbf{q}; \boldsymbol{\theta})\,\ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}; \boldsymbol{\theta}) = \boldsymbol{\tau}(\mathbf{u}; \boldsymbol{\theta}) + \mathbf{J}^\top \mathbf{F}_\text{contact}$$

**变量含义**：
- $\mathbf{q} \in \mathbb{R}^{n_q}$ — 关节角度 (位形)。
- $\dot{\mathbf{q}}, \ddot{\mathbf{q}}$ — 关节角速度、角加速度。
- $\mathbf{M}(\mathbf{q}; \boldsymbol{\theta}) \in \mathbb{R}^{n_q \times n_q}$ — **质量矩阵**, 与位形 + 硬件参数有关。
- $\mathbf{C}(\mathbf{q}, \dot{\mathbf{q}}) \dot{\mathbf{q}}$ — **科氏 + 离心力** (与速度的二次项)。
- $\mathbf{g}(\mathbf{q}; \boldsymbol{\theta})$ — **重力项**, 取决于位形和质量分布。
- $\boldsymbol{\tau}(\mathbf{u}; \boldsymbol{\theta})$ — **关节驱动扭矩**, 由控制 $\mathbf{u}$ 和硬件 $\boldsymbol{\theta}$ (例如电机增益) 决定。
- $\mathbf{J}$ — 接触点处的雅可比矩阵 (把接触力映射到关节扭矩)。
- $\mathbf{F}_\text{contact}$ — 接触力。

**公式解读**：左侧 = 惯性力 + 离心力 + 重力, 右侧 = 主动驱动 + 接触作用。这就是 **拉格朗日动力学** 的标准形式。

**关键**: 所有项 ($\mathbf{M}, \mathbf{C}, \mathbf{g}, \boldsymbol{\tau}, \mathbf{F}_\text{contact}$) 都对 $\boldsymbol{\theta}$ 可微。

### 2.4 时间积分

半隐式 Euler:
$$\dot{\mathbf{q}}_{t+1} = \dot{\mathbf{q}}_t + dt \cdot \ddot{\mathbf{q}}_t$$
$$\mathbf{q}_{t+1} = \mathbf{q}_t + dt \cdot \dot{\mathbf{q}}_{t+1}$$

**变量含义**：$dt$ 时间步长 (典型 $10^{-3}$ s)。

**公式解读**：先用当前加速度更新速度, 再用 **新速度** (而非旧速度) 更新位置, 提供更好的稳定性。

### 2.5 任务损失

$$L(\boldsymbol{\theta}, \mathbf{u}_{0:T-1}) = \sum_{t=0}^{T-1} \ell(\mathbf{s}_t, \mathbf{u}_t) + \ell_\text{terminal}(\mathbf{s}_T)$$

**变量含义**：
- $\ell$ — 每步损失 (例如能耗、违规惩罚)。
- $\ell_\text{terminal}$ — 末态损失。
- $\mathbf{s}_t$ — 状态 (含 $\mathbf{q}_t, \dot{\mathbf{q}}_t$)。

例如抓取: $\ell_\text{terminal} = \|\mathbf{x}_\text{obj}^T - \mathbf{x}^*\|^2$, 即"物体最终位置 vs 目标"距离平方。

### 2.6 联合梯度更新

$$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \eta_\theta \nabla_\theta L$$
$$\mathbf{u}_t \leftarrow \mathbf{u}_t - \eta_u \nabla_{u_t} L,\quad t = 0, ..., T-1$$

**变量含义**：
- $\eta_\theta, \eta_u$ — 学习率 (硬件 / 控制各自一个, 因尺度不同)。

**公式解读**：标准梯度下降, 通过 PyTorch / 自定义 AD 反传计算梯度。

## 3 · 算法

```
─── DiffHand Algorithm ──────────────────────
输入: 初始硬件 θ_0, 任务损失 L
重复 epoch = 1..N_epoch:
    s_0 ← reset()
    for t = 0..T-1:                      # 正向 rollout
        u_t = π_φ(s_t)  (或预定义)
        s_{t+1} = sim(s_t, u_t; θ)       # 可微!
    L_total = Σ_t ℓ(s_t, u_t)
    g_θ = ∇_θ L_total                    # 反向传播
    g_u = ∇_u L_total
    θ ← θ - η_θ g_θ
    u ← u - η_u g_u
返回 θ*, u*
```

## 4 · 实验

### 4.1 任务列表
1. **DiffHand 抓取** — 优化手指几何 + 抓取轨迹。
2. **机械臂抛球** — 优化臂质量分布 + 抛接时机。
3. **多步操纵** — 优化整套运动序列 + 形态。

### 4.2 关键发现 — 初始化敏感性

**核心实验**: 从 50 个随机种子启动训练, 分别得到 50 个最优硬件 $\boldsymbol{\theta}^*$。

```
50 次重复优化 ↓
├── 25% 收敛到 "胖手指" 设计, 抓取率 80%
├── 35% 收敛到 "细长指" 设计, 抓取率 65%
├── 30% 收敛到局部极小, 抓取率 < 50%
└── 10% 训练发散
```

任务成功率方差 > 30% → **梯度优化对初值极敏感**。

### 4.3 平滑接触 anneal 策略

实验显示: 固定 $\epsilon$ 训练失败率高, 逐步 anneal $\epsilon$ 显著提升收敛率:

$$\epsilon(t) = \epsilon_0 \cdot \gamma^t,\quad \gamma \approx 0.99$$

**变量含义**：
- $\epsilon_0$ — 初始平滑系数 (大, 例 $10^{-2}$)。
- $\gamma < 1$ — 衰减率。
- $t$ — 训练步数。

**公式解读**：每步 $\epsilon$ 略减小, 让训练初期 "看到平滑接触梯度", 后期逐渐逼近真实硬接触。是 **课程学习 (curriculum)** 思想。

## 5 · 关键贡献

1. **平滑接触公式**: softplus 替代硬接触, 让梯度处处可微。
2. **端到端可微管道**: 硬件 → 动力学 → 损失全链路 AD。
3. **暴露问题**: 系统证明可微 co-design 的 **初值敏感** 与 **多局部极小** —— 为后续工作 (代理路线、多任务联合) 提供动机。

---

## 6 · 局限

1. **维度受限**: 硬件参数 $d_h \le 50$ 才能稳定收敛。
2. **训练慢**: 单次 rollout 需完整可微仿真。
3. **接触平滑残留误差**: 真机部署时 $\epsilon \to 0$ 仍有偏差。
4. **不支持拓扑变化**: 离散结构需另一套方法 (RoboGrammar 等)。
