## 🎯 这篇论文想做什么

[[Ref-19-Hu-2020-DiffTaichi|DiffTaichi]] 等可微物理工具已经能对软体/流体求导，但 **接触 (contact)** 一直是难题——一旦两个物体碰上，梯度就会跳变或为零。Xu 等的目标：

> 构建一个 **能处理接触的、端到端可微分的机器人设计框架**，让"几何参数 → 控制 → 任务表现" 整条链路梯度都通。

具体应用：让算法自己优化机械手的 (a) 手指长度、(b) 关节安装位置、(c) 电机参数，同时优化抓取轨迹，最大化抓取成功率。

---

## 🛠️ 实现路径

### 1. 平滑接触模型

传统接触：`if penetration > 0 then force else 0` —— 梯度跳变。
Xu'21 用 **指数平滑**：
$$F_\text{contact}(d) = k \cdot \log(1 + e^{-d/\epsilon})$$
- $d$：穿透距离 (正即重叠)。
- $\epsilon$：平滑系数，越小越接近 hard contact。
- 梯度处处定义、连续。

### 2. 关节力学可微

机械手由"刚体 + 关节 + 腱" 组成。每段连杆的长度、电机位置、腱路径都参数化为可学变量 $\theta$。前向动力学：
$$\mathbf{q}_{t+1} = \mathbf{q}_t + \dot{\mathbf{q}}_t \,dt + \tfrac{1}{2}\ddot{\mathbf{q}}_t\,dt^2$$
$$\ddot{\mathbf{q}}_t = \mathbf{M}^{-1}(\mathbf{q})\big[\boldsymbol{\tau}(\mathbf{a}, \theta) - \mathbf{C}\dot{\mathbf{q}} - \mathbf{g} - \mathbf{J}^\top \mathbf{F}_\text{contact}\big]$$
所有项均可微。

### 3. 联合优化目标

定义任务 loss (例如抓取重物时的位移误差)：
$$L(\theta, \phi) = \sum_t \|x_\text{obj}(t) - x_\text{target}\|^2$$
其中 $\phi$ 是控制策略的参数 (轨迹或网络权重)。

**联合更新**：
$$\theta \leftarrow \theta - \alpha\,\nabla_\theta L,\quad \phi \leftarrow \phi - \alpha\,\nabla_\phi L$$

### 4. 实验

- DiffHand: 优化手指长度让抓取距离最小。
- 抛接球：优化机械臂质量分布让抛准度最高。
- 多步操作：优化整套轨迹和形态。

## 📐 关键公式与使用场景

### 公式 1：平滑接触
$$F_\text{contact}(d) = k\log(1 + e^{-d/\epsilon})$$

**使用场景**：
- 让"是否接触" 的梯度处处可导，避免训练时梯度断裂。
- $\epsilon$ 大 → 训练前期保平滑；逐渐减小到 0 → 后期接近真实硬接触。

### 公式 2：关节空间动力学
$$\ddot{\mathbf{q}} = \mathbf{M}^{-1}[\boldsymbol{\tau} - \mathbf{C}\dot{\mathbf{q}} - \mathbf{g} - \mathbf{J}^\top\mathbf{F}_c]$$

**使用场景**：
- 把硬件参数 (连杆长度 → 影响 $\mathbf{M}, \mathbf{J}, \mathbf{C}$) 反向传播到任务表现。
- 这条链路 **就是 co-design 梯度的核心**。

### 关键发现 (论文 §5)：初值敏感性

实验：从随机初始化跑 50 次，最终设计差异巨大；任务成功率方差 > 30%。

**结论**：可微分梯度虽强，但 **梯度坑** 多——损失景观非凸、初值决定收敛方向。

## 🔑 对本论文 (Yi'25) 的关键意义

本论文 §Related Work 引用 Xu'21 的两段话：
1. "differentiable simulations offer promising co-design directions ... but require smooth, tractable gradients";
2. "are often sensitive to initialization [4, 20, 21]"。

也就是说，**Xu'21 是反面教材** 之一：
- 优点：完整可微、思想正确。
- 缺点：FEM + 接触 + 机械臂的复合梯度数值不稳，**初值敏感** + **训练慢**。

本论文的对策是 **不直接用物理梯度**，而是：
1. 用 Warp 生成数据 (前向不需梯度，只要快)。
2. 训 NN 代理 (代理本身平滑可微)。
3. 在代理上做梯度下降。
4. 多物体联合优化 → 缓解局部极小。

→ Fig 4d 显示，本论文比 DiffSim 快 **3 个数量级**，梯度噪声更小。
