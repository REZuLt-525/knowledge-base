## 1 · 研究问题

微创手术内窥镜需要 **互相矛盾** 的两种状态:
- 先 **柔顺穿入** 蜿蜒血管 / 通道。
- 再 **刚硬定位** 在目标位置。

颗粒阻塞 ([[Ref-34-Wei-2016-ParticleJamming|Wei'16]])、层阻塞 ([[Ref-38-Narang-2017-LaminarJamming|Narang'17]]) 都需 **真空源** — 在体内不便。Seoul 大学 Cho Kyu-Jin 团队的目标:

> 用 **纯机械几何** 实现 **连续变刚度** (CVS): 仅靠 **同轴管的相对旋转** 即可在数量级范围调节弯曲刚度 — 无需真空 / 充气 / 加热。

## 2 · 同轴管 CVS 原理

### 2.1 双管嵌套结构

两个 **同心嵌套** 的薄壁管:
```
横截面:
   外管 (直径 D_o, 壁厚 t)
      ⌒⌒⌒⌒⌒⌒
     ┃         ┃
     ┃   内管  ┃
     ┃ (D_i)   ┃
      ⌒⌒⌒⌒⌒⌒
```

每根管壁上 **激光切割图案** (周期性切口、孔洞)。

### 2.2 非均匀图案

外管和内管的图案 **不同**:
- 外管: 切口分布 $f_o(s)$ (沿长度 $s$)。
- 内管: 切口分布 $f_i(s)$, 与 $f_o$ 错相位。

定义 **重叠率** $\eta(s, \theta)$:
- $\theta = 0$ (对齐): 切口重合 → 整体弱化, $\eta$ 高。
- $\theta = \pi$ (错开 180°): 切口被覆盖 → 整体强化, $\eta$ 低。

**变量含义**：
- $s$ (m) — 沿管长方向坐标。
- $\theta$ (rad) — 内外管相对旋转角。
- $\eta(s, \theta)$ — 该位置切口重叠率 (0-1)。

## 3 · 等效刚度数学

### 3.1 局部弯曲刚度

每段位置 $s$:
$$EI_\text{eff}(s, \theta) = EI_0(s) \cdot f(\eta(s, \theta))$$

**变量含义**：
- $EI_\text{eff}$ — 等效弯曲刚度 (受 $s, \theta$ 影响)。
- $EI_0$ — 无切口时标称刚度 (取决于材料 + 截面)。
- $f$ — **覆盖函数** (随 $\eta$ 单调减): 重叠多 → 刚度小。

经验拟合:
$$f(\eta) = 1 - \alpha \cdot \eta$$

**变量含义**：
- $\alpha$ — 拟合系数, 取决于切口尺寸与管厚比例 (典型 0.7-0.95)。

**公式解读**：完全错开 ($\eta=0$) 时 $f = 1$ (满刚度); 完全重叠 ($\eta=1$) 时 $f = 1 - \alpha \approx 0.05-0.3$ (大幅弱化)。

### 3.2 整体弯曲刚度 (串联)

整管多段串联, **总弯曲柔度** (compliance) 累加:
$$\frac{1}{K_\text{bending}(\theta)} = \int_0^L \frac{ds}{EI_\text{eff}(s, \theta)}$$

**变量含义**：
- $L$ (m) — 管总长。
- $K_\text{bending}$ (N·m/rad) — 总弯曲刚度。
- $1/K$ — 柔度 (compliance, 刚度的倒数)。
- $1/EI_\text{eff}$ — 局部柔度。

**公式解读**：串联系统的总柔度 = 局部柔度的积分, 类似电路中"串联电阻总值 = 各分量之和"。

整体刚度:
$$K_\text{bending}(\theta) = \left[\int_0^L \frac{ds}{EI_0(s) \cdot f(\eta(s, \theta))}\right]^{-1}$$

### 3.3 刚度切换比

通过精细图案设计, 实测:
$$\frac{K_\text{max}}{K_\text{min}} \sim 10 - 1000$$

**公式解读**：通过设计切口形状, 可在 1-3 个数量级范围调节 (取决于切口比例与图案错相位)。

## 4 · 制造与应用

### 4.1 激光切割薄壁管
- 不锈钢管, 直径 ~5 mm, 壁厚 50 μm。
- 飞秒激光精度 ~50 μm。

### 4.2 应用: 微创手术

```
末端工具 (镊子 / 切割器)
     │
     │ 同轴管 (5 mm 直径, 50 cm 长)
     │
     ▼
手柄 (旋转输入)
```

外科医生扭动手柄 → 改变相对相位 → 改变刚度。

工作流:
```
─── 阶段 1: 导航 (软态) ──────────────────
旋转手柄到 θ = 0 (对齐, 软)
推进入血管, 软态贴合弯曲

─── 阶段 2: 锁定 (硬态) ──────────────────
到达目标后旋转手柄到 θ = π (错开, 硬)
管硬化锁定形状

─── 阶段 3: 操作 ────────────────────────
末端工具进行夹取 / 切除
```

### 4.3 性能指标
- 切换时间 ~0.5 秒。
- 直径 ~5 mm。
- 弯曲半径 ~30 mm。
- 重复操作 $10^4$ 次无疲劳。

## 5 · 关键贡献

1. **纯机械 CVS**: 无真空 / 加热 / 电磁辅助。
2. **连续刚度调节**: 与离散开关 (颗粒阻塞) 区别开。
3. **数学模型 + 实测**: 重叠率公式经实验验证。
4. **微创手术原型**: 真实临床应用前景。

---

## 6 · 局限

1. **制造精度高**: 飞秒激光昂贵。
2. **相对旋转限制**: 死区难处理。
3. **大变形限制**: 切口处疲劳裂纹。
4. **不能局部变刚度**: 整管同步变化。
