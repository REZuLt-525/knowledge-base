# [5] Chen, He, Ciocarlie 2020 · Hardware as Policy (HaaP)

> **引用**: T. Chen, Z. He, M. Ciocarlie. *Hardware as policy: Mechanical and computational co-optimization using deep reinforcement learning.* arXiv:2008.04460, 2020.

`#文献-方法` `#强化学习` `#Co-Design`

---

## 🎯 这篇论文想做什么

机器人的硬件设计和控制策略一直是 **两条独立优化链**：
- 机械工程师用 SolidWorks + FEA 调硬件；
- 算法工程师用 RL/MPC 调策略。

Chen 等问：

> 既然 RL 已经能用一组参数 (神经网络权重) 描述策略，能不能 **把硬件参数也作为策略的一部分**，让 RL 同时学硬件和软件？

具体目标：在 PyBullet/MuJoCo 中演示双 RL 共优化——硬件参数 + 控制策略一同更新。

---

## 🛠️ 实现路径

### 关键观点：硬件就是固定参数化的策略

把策略写为：
$$\pi(a|s; \phi, h)$$
- $\phi$：控制策略神经网络权重；
- $h$：硬件参数 (e.g., 手指长度、电机最大扭矩、关节摩擦)。

每次仿真前，环境会根据 $h$ 重新构建机器人；策略 $\pi$ 在这个机器人上跑。

### 算法 (PPO + 硬件梯度)

```
重复 t = 1, 2, ...
   1) 用当前 (φ, h) 构造仿真环境
   2) 收集轨迹批数据
   3) PPO 更新 φ
   4) 把硬件参数 h 视为策略一部分, 用 REINFORCE/PPO 同时更新 h
   5) (可选) 周期性把 h 截断到可制造范围
```

由于 $h$ 影响仿真物理 (而仿真不可微)，论文用 **REINFORCE 估计** $\nabla_h J$：
$$\nabla_h J(h, \phi) \approx \mathbb{E}_\tau\left[R(\tau)\nabla_h \log p(\tau|h, \phi)\right]$$

### 顺序图结构 (Sequential Graph)

为减少高维硬件搜索的难度，论文提出：
1. 先优化 **粗粒度参数** (总长度)；
2. 收敛后再放开 **细粒度参数** (每段长度、关节安装角)；
3. 像剥洋葱一样从粗到细。

### 实验

- **5-DoF 抓取任务**：让机器人抓特定形状物体。
- **机械臂抛接球**：优化臂长 + 接球时机。
- 与"先固定硬件再训策略" 对比：硬件-策略联合显著提高成功率 ≥ 15%。

## 📐 关键公式与使用场景

### 公式 1：硬件视为策略变量
$$\pi(a|s;\phi, h),\quad J(\phi, h) = \mathbb{E}\left[\sum_t \gamma^t r_t\right]$$

**使用场景**：
- **机械臂结构调优**：连杆长度 / 电机扭矩 / 减速比。
- **夹爪几何**：齿数、间距。
- **本论文 (Yi'25) 的对应**：本论文不学策略 RL，但**联合优化"22D 刚度 + 6D 位姿"** 在思想上一致 —— 都是把"硬件参数 + 决策" 放入同一优化目标。

### 公式 2：REINFORCE 硬件梯度
$$\nabla_h J \approx \mathbb{E}\left[R(\tau)\nabla_h \log p(\tau|h)\right]$$

**使用场景**：当物理仿真不可微时，用 score function 估计硬件梯度。
**坑**：方差大，需要大量样本——这正是 [[Ref-07-He-2024-MORPH|MORPH]] 后续要解决的问题 (用可微硬件代理代替 REINFORCE)。

---

## 🎯 实战要点

- **硬件参数空间** 必须先归一化到可制造范围。
- **渐进式 unfreezing**：先固定 $h$ 让 $\phi$ 学好，再放开 $h$。
- **硬件正则化**：避免 RL 学出"造一把无穷长的手指"。

---

## 🔑 对本论文 (Yi'25) 的关键意义

- **思想直系前辈**：本论文外层位姿采样 + 内层刚度优化的结构，本质上还是"硬件作为可学参数"。
- **关键差异**：
  - HaaP 用 RL 估计硬件梯度 (高方差、慢)；
  - 本论文用 **NN 代理直接给解析梯度** (低方差、快 1000 倍)；
  - HaaP 学"长序列轨迹策略"；本论文是"位姿候选 + 末态评估" —— 任务结构更简单，让代理路线足够。
- **HaaP → MORPH → 本论文** 是同一思想流派的三次迭代：从"REINFORCE" 到"可微代理"，再到 "代理 + 采样混合"。
