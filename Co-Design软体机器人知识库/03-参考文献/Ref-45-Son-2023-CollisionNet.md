# [45] Son & Kim 2023 · Local Object Crop Collision Network

> **引用**: D. Son and B. Kim. *Local object crop collision network for efficient simulation of non-convex objects in GPU-based simulators.* arXiv:2304.09439, 2023.

`#文献-方法` `#神经物理` `#碰撞`

---

## 🎯 这篇论文想做什么

GPU 仿真器 (Isaac Gym, Brax 等) 对**凸物体** 的碰撞计算很快，但 **非凸物体** 要么需要凸分解 (慢且不准)，要么用昂贵的精确算法 (如 GJK + EPA)。Son 等提出：

> 训一个 **小型 CNN** 直接学习 "两物体局部点云 → 是否碰撞 + 接触点" 的函数，用神经网络替代传统几何算法。

应用：在 GPU 仿真器中加速大规模非凸物体场景 (例如成百上千个杂乱物体)。

---

## 🛠️ 实现路径

### 1. 数据预处理

对每个物体对 $(O_1, O_2)$ 在某个相对位姿下：
- 提取 **局部裁剪 (local crop)**：以接触候选点为中心，截取小立方体内部点云。
- 用经典精确算法计算 **真值** (是否碰撞 + 接触点位置 + 接触法线)。

### 2. 网络结构

```
两物体局部 crop (32 × 32 × 32 voxel)
        │
        ▼ 3D CNN
全局碰撞特征
        │
        ├── 二分类头: 是否碰撞 (BCE loss)
        └── 回归头: 接触点 + 法线
```

### 3. 训练

- 监督学习，使用 GJK/EPA 算法生成 ground truth。
- 损失 = 二分类损失 + 接触点 L2 损失。

### 4. 部署

- 在仿真器主循环中：用 CNN 替代 GJK 调用。
- 实测：非凸物体碰撞计算 **快 5-10 倍**。

## 📐 关键技术与使用场景

### 技术 1：局部裁剪
**思想**：碰撞只发生在物体表面附近的小区域，不需要看整个物体。

**使用场景**：
- 大规模物理仿真 (机器人 + 多物体场景)。
- 非凸抓取仿真：物体形状复杂时降本。

### 技术 2：神经网络替代几何算法
**含义**：把"明确算法步骤" 转换为"参数化函数 + 数据"。

**使用场景**：
- **CollisionNet 在 RL 训练中加速**：每步几千次碰撞查询。
- **本论文 (Yi'25) 同思想**：把 FEM 模拟器替换为 NN 代理。

## 🔑 对本论文的意义

本论文 §3.3 引用此文作为 **"神经网络可以高效编码物理"** 的论据：

> "Neural network is shown to compile physics efficiently [45]."

即：CollisionNet 证明了在 **接触物理** 这一难题上 NN 是可行的；本论文则把它推广到 **整个 FEM 软体仿真**——更激进、覆盖更广。
