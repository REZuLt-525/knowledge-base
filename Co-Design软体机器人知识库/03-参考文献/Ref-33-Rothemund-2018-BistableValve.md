## 1 · 研究问题

软体机器人通常依赖 **外部电磁阀 + 控制板** 来开关气压 — 这违背 "全软" 哲学。哈佛 George Whitesides 团队 (软体机器人鼻祖) 与 Zhigang Suo (固体力学大牛) 合作的目标:

> 用 **纯软材料 + 特殊几何** 实现 **双稳态阀**: 无需电子, 气压超阈值即"咔哒" 一声切换状态 — 把电子电路里的"晶体管" 替换为软材料结构。

意义: 全软自主机器人, 抗强磁、抗爆、可吞咽。

## 2 · 双稳态结构数学

### 2.1 双井势能

双稳态 = 系统有 **两个稳定平衡点 + 一个不稳定中间点**:

```
势能 U(θ)
   ▲
   │  ╱──╲       ╱──╲
   │ ╱    ╲     ╱    ╲
   │/      ╲   ╱      ╲
   │        ╳            ← 中间不稳
   └─────────────────→ θ
   状态 A    最大     状态 B
```

数学表达:
$$U(\theta) = a(\theta - \theta_A)^2(\theta - \theta_B)^2$$

平衡条件 $U'(\theta) = 0$ 有三个零点 $\theta_A, \theta_C, \theta_B$:
- $U''(\theta_A), U''(\theta_B) > 0$: 稳定。
- $U''(\theta_C) < 0$: 不稳。

### 2.2 Snap-through 跳转

外力 $F$ 推动系统从 $\theta_A$ 越过 $\theta_C$ → 自动落入 $\theta_B$:
$$F_\text{trigger} = \max_{\theta \in [\theta_A, \theta_B]} U'(\theta)$$

跳转时 **机械能下降为动能 + 阻尼耗散**, 是不可逆过程 (类似电子开关)。

## 3 · 几何实现 — 弯曲薄壳

### 3.1 软板的非线性力学

把硅胶薄板做成 **预弯曲曲面** (类似快门片). 在中点位移 $\delta$ 与受力 $F$ 关系上:
$$F(\delta) = k_1 \delta - k_2 \delta^2 + k_3 \delta^3$$

是一个 **S 形** 曲线 (不单调):
```
F
 │
 │      __
 │     /  \
 │   /     \
 │  /       \____
 │ /             \____
 │/                   \___
─┼─────────────────────────→ δ
 │
```

### 3.2 负刚度区域

在 $F-\delta$ 中段, $\dfrac{dF}{d\delta} < 0$:
- 直观: 越压越容易压。
- 后果: 一旦受力超阈值, 系统加速跳到下一稳态。

### 3.3 临界跳转条件

$$P_\text{crit} = \frac{U_\text{barrier}}{V_\text{eff}}$$
- $U_\text{barrier}$: 势垒高度 (由几何 + 材料决定)。
- $V_\text{eff}$: 受气压作用的有效体积。

## 4 · 阀门集成

### 4.1 单阀结构

```
气流入口 → ┌─────┐ → 气流出口
           │ ◢◣  │  ← 双稳态薄板
           │  ◢◣ │
           └─────┘
```

- 状态 A: 板弯向通道 → 阀关闭。
- 状态 B: 板弯离通道 → 阀打开。
- 气压跨阈值即触发跳转。

### 4.2 多阀串联

把若干双稳态阀 + 气体储罐 + 细通道组合, 实现 **流体振荡器** (类电子 RC 振荡):
```
气源 → 阀 1 → 储罐 1 → 阀 2 → 出口
           ↑                ↓
           └── 反馈通道 ←────┘
```

气压周期切换 → 软机器人自激爬行 / 跳跃。

## 5 · 全软机器人 demo

### 5.1 自主爬虫

文中演示:
- 单气源 (压缩气罐)。
- 双稳态阀 + 4 个气动腿。
- **无电子**, 节奏运动, 速度 ~5 cm/s。

### 5.2 流体逻辑门

更复杂的双稳态组合实现:
- AND 门: 两入口都高压才切换。
- OR 门: 任一入口高压触发。
- NOT 门: 高压关闭。

## 6 · 关键贡献

1. **纯软双稳态阀**: 首次完全软材料实现快速 snap-through。
2. **流体晶体管模型**: 类比电子电路, 软材料实现逻辑门。
3. **全软自主示范**: 单气源 + 软体 = 自主行为。
4. **设计公式**: $P_\text{crit}$ 与几何参数的定量关系。

---

## 7 · 局限

1. **不可重置**: 跳转后需反向气压切换。
2. **时间常数大**: 受软材料阻尼影响, 频率 < 10 Hz。
3. **温度敏感**: 硅胶模量随温度变。
4. **不能精确控制**: 二态切换, 不连续控制。
