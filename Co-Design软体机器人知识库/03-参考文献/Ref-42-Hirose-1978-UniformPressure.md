# [42] Hirose & Umetani 1978 · 均匀压力软夹爪

> **原文**: S. Hirose and Y. Umetani. *The development of soft gripper for the versatile robot hand.* **Mechanism and Machine Theory**, 13(3):351-359, 1978.
> **译名**: 《面向通用机器手的软体夹爪研发》 — *机构与机器理论*, 1978.

`#文献-经典` `#均匀压力` `#里程碑`

---

## 1 · 研究问题

1970 年代末，工业机器人末端夹爪几乎全是 **平行夹钳**——只能抓"形状已知、规则" 的零件。东京工业大学 Shigeo Hirose 提出根本性挑战:

> **能否设计一种夹爪, 让它"贴着"任意形状物体的轮廓抓握, 而不是用两个平面去夹?** 而且只用一个驱动源 (单根腱), 就能让多个关节联动出"包络物体表面"的运动?

如果可以, 这就是 "**通用 (versatile) 抓手**" 的雏形。Hirose 的目标是给出 **解析的设计公式**, 让工程师能直接按公式造出原型。

---

## 2 · 系统形式化

### 2.1 硬件结构

夹爪由 $N+1$ 个 **多段链 (multi-link chain)** 组成, 每个关节左右各有一个滑轮 (pulley), 用一根 **链条 (chain)** 把所有滑轮串起来:

```
      P_0 ── P_1 ── P_2 ── ... ── P_N
       │      │      │              │
       (k=k₀)(k=k₁) (k=k₂)         (k=k_N)
                          ← 关节弹簧
                  ↓
              一根腱 (cable) 沿滑轮通过
```

**几何参数**:
- $L$ (m) — 整指长度。
- $H$ (m) — 指根处腱距铰链中心轴的高度。
- $l_i$ (m) — 第 $i$ 个 waypoint 到指根的弧长。
- $h_i$ (m) — 第 $i$ 个 waypoint 到对应铰链中心轴的高度 (设计变量)。

### 2.2 受力分析

**腱拉力**:
- 假设腱内张力沿途均匀, 因滑轮无摩擦: $T = $ 常数 (单位 N)。
- 每段腱的方向沿相邻 waypoint 连线。

**关节力臂力矩**:
$$M_i = T \cdot h_i$$

**变量含义**：
- $M_i$ (N·m) — 关节 $i$ 处的腱产生的力矩。
- $T$ (N) — 腱拉力 (常数)。
- $h_i$ (m) — 力臂 (waypoint 到铰链中心的距离)。

**公式解读**：扭矩 = 力 × 力臂, 标准定义。

### 2.3 把手指视为梁

设连续化弯矩 $M(l)$, **梁理论** 给出:
$$\frac{d^2 M(l)}{d l^2} = w(l)$$

**变量含义**：
- $l$ (m) — 沿手指的距离参数。
- $M(l)$ (N·m) — 距离 $l$ 处的总弯矩。
- $w(l)$ (N/m) — **分布载荷**: 单位长度上的横向力。

**公式解读**：弯矩对距离的二阶导 = 分布载荷, 是 Euler-Bernoulli 梁理论基本方程。

## 3 · 均匀压力公式推导 ⭐ (核心数学)

### 3.1 设计目标 — 均匀压力假设

让整个手指 **均匀贴合物体** — 数学上即让分布弯曲压力 $w(l)$ 沿手指 **常数**:

$$\frac{d^2 M(l)}{dl^2} = c \quad (c > 0, \text{ 均匀压力常数})$$

**变量含义**：
- $c$ — 待定常数 (单位 N/m), 表示分布载荷强度。

**公式解读**：分布载荷为常数 = 沿手指每点贡献相同弯矩源。这是 **均匀压力** 的数学表达。

### 3.2 边界条件

指尖自由端 (无外力):

$$\left.\frac{dM}{dl}\right|_{l=L} = 0$$

**含义**：剪力为零 — 因为指尖之外没有任何外力。

$$M(L) = 0$$

**含义**：弯矩为零 — 同样因为指尖外没有产生弯矩的源。

### 3.3 第一次积分

$$\frac{dM}{dl} = \int c\, dl = c \cdot l + C_1$$

**变量含义**：$C_1$ 是待定积分常数。

代入边界条件 $\frac{dM}{dl}|_{l=L} = 0$:
$$0 = c \cdot L + C_1 \;\Rightarrow\; C_1 = -cL$$

故:
$$\frac{dM}{dl} = c(l - L)$$

**公式解读**：剪力沿手指线性分布, 指尖为 0, 根部为 $-cL$ (最大反向)。

### 3.4 第二次积分

$$M(l) = \int c(l - L)\, dl = \frac{c}{2}(l - L)^2 + C_2$$

代入边界条件 $M(L) = 0$:
$$0 = \frac{c}{2}(L - L)^2 + C_2 = C_2 \;\Rightarrow\; C_2 = 0$$

**最终结果**:
$$\boxed{M(l) = \frac{cL^2}{2}\left(1 - \frac{l}{L}\right)^2}$$

**公式解读**：弯矩 $M(l)$ 沿手指 **二次衰减**:
- 根部 $l = 0$: $M(0) = cL^2/2$ (最大值)。
- 中段 $l = L/2$: $M = cL^2/8$ (1/4 最大值)。
- 指尖 $l = L$: $M(L) = 0$。

### 3.5 推回 waypoint 高度

由 $M_i = T \cdot h_i$ 即 $M(l_i) = T \cdot h_i$:

$$T \cdot h_i = \frac{cL^2}{2}\left(1 - \frac{l_i}{L}\right)^2$$

定义 $H = \dfrac{cL^2}{2T}$ (这个量在指根 $l=0$ 处的值就是 $h_0$, 故 $H$ 是指根处力臂):

$$\boxed{h_i = H\left(1 - \frac{l_i}{L}\right)^2}$$

**变量含义**：
- $h_i$ (m) — 第 $i$ 个 waypoint 到铰链中心轴的高度 (设计变量)。
- $H$ (m) — 指根处的高度 (最大力臂)。
- $l_i / L \in [0, 1]$ — 归一化距离。

**公式解读**：
- 根部 ($l=0$): $h_0 = H$ — 腱离铰链最远, 力臂最大。
- 中段 ($l = L/2$): $h = H/4$ — 急剧下降。
- 指尖 ($l = L$): $h_N = 0$ — 腱穿过铰链中心, 力臂为 0。

腱走线呈 **二次衰减曲线**:

```
指根                                    指尖
═●═══════════════════════════════════●
 │ H  ╲                              │
 │     ╲                             │
 │      ╲___                         │
 │          ╲___                     │
 │              ╲___                 │
 │                  ╲╲___           │
 │                       ╲╲___      │
 │                            ╲╲══●←0
```

## 4 · 物理直觉 (为何这样布线?)

### 4.1 等距 vs 均匀压力 对比

如果腱 **等距分布** ($h_i = H$ 常数):
$$M(l) = T \cdot H = \text{常数}$$

→ 远端弯矩 = 近端弯矩, 但远端关节弹簧反力较小 (因为远端关节较少受其他关节的反向力) → **远端弯曲过度**, 手指 "**卷起来**" 只用指尖触物。

均匀压力布线:
$$M(l) = \frac{cL^2}{2}(1 - l/L)^2 \to 0 \text{ at tip}$$

→ 弯矩 **从根部线性递减到指尖**, 让每段关节都参与变形, **整指均匀贴合**。

### 4.2 实验对比

| 走线方式 | 物理结果 |
|---|---|
| 等距 ($h_i = H$) | 指尖卷起, 只指尖触物 |
| 均匀压力 ($h_i = H(1 - l_i/L)^2$) | 整根贴合物体 |

## 5 · 实验 (1978 论文 + 后续验证)

Hirose 团队制造了原型:
- 7 个关节、单电机驱动。
- 抓取数十种不规则形状物体 (蔬菜、瓶子、工具)。
- 成功率显著优于平行夹钳。

后续半个世纪持续验证:
- [[Ref-43-Glick-2018-GeckoGripper|Glick 2018]] 把公式扩展到 **气动软体**。
- 本论文 (Yi'25) 把公式扩展到 **腱驱动 + 柔性铰链**。

---

## 6 · 关键贡献

1. **均匀压力概念**: 用一个简单 ODE 推出整指贴合的设计公式。
2. **解析 + 工程化**: 公式直接可用, 无需数值求解。
3. **欠驱动思想雏形**: 单腱驱多关节, 启发几十年后的 SDM Hand 等设计。
4. **形态计算先驱**: 把"贴合行为" 编码到几何中, 节省运行时控制。

---

## 7 · 局限

1. **小变形假设**: 大变形需椭圆积分修正。
2. **忽略关节弹簧反力**: 实际关节有恢复力矩, 完整推导需考虑。
3. **腱无摩擦假设**: 真实滑轮 / 通道有摩擦, 远端张力略小。
4. **几何对称**: 复杂几何需分段处理。

---

## 8 · 历史影响

- 几乎所有 **欠驱动腱驱动手** 设计的理论起点。
- SDM Hand ([[Ref-10-Odhner-2014-SDMhand]])、Pisa-IIT SoftHand、本论文 (Yi'25) 都直接或间接继承此公式。
- Hirose 本人是日本机器人学奠基者: 蛇形机器人 ACM 系列、爬虫 TITAN、Spider Robot 等。

本论文 §3.2 第一句明确写道:
